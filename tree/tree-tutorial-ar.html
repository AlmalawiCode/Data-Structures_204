هرمية، غير خطية، فروع ومستويات

🔑 الفرق الجوهري

جميع هياكل البيانات السابقة (المصفوفة، القائمة المرتبطة، المكدس، الطابور) هي هياكل خطية (Linear) — تتنقّل خلالها خطوة واحدة في كل مرة وفي اتجاه واحد. أما الشجرة فمختلفة تمامًا: إنها غير خطية (Non-Linear) وهرمية (Hierarchical)، وهذا ما يجعلها قوية في تمثيل العلاقات في العالم الحقيقي.

تُعدّ الشجرة من أهم هياكل البيانات في علوم الحاسب كلها؛ فأنظمة الملفات في أنظمة التشغيل، وخوارزميات البحث، والمترجمات (Compilers)، وقواعد البيانات، وأشجار القرار في الذكاء الاصطناعي، كلها مبنية على هياكل شجرية. هيا نكتشف السبب!

3هياكل البيانات الخطية مقابل غير الخطية

هذا هو المفهوم الأكثر جوهرية الذي يجب فهمه. ماذا يعني أن يكون هيكل البيانات خطيًا أو غير خطي؟

■ المصفوفة — خطية، ذاكرة متتالية

تُخزَّن العناصر في مواقع ذاكرة متتالية؛ يأتي كل عنصر مباشرة بعد الآخر، والحركة في اتجاه واحد: إلى الأمام.

🔗 القائمة المرتبطة — خطية، ذاكرة متفرقة

تُخزَّن العقد (Nodes) في عناوين ذاكرة عشوائية (متفرقة). ومع ذلك، تخزّن كل عقدة عنوان العقدة التالية (مرجع)، لذلك نجتازها بترتيب خطي تسلسلي. فهي متفرقة في الذاكرة، لكن ترتيبها المنطقي يبقى خطيًا.

المصفوفة والقائمة المرتبطة: كلتاهما خطية. لكل عنصر/عقدة سابق واحد ولاحق واحد بالضبط، ولا يمكنك التحرك إلا في اتجاه واحد.

🌳 الشجرة — غير خطية، هرمية

في الشجرة، يمكن أن ترتبط العقدة الواحدة بعدة أبناء. ومن أي عقدة يمكنك النزول إلى اليسار أو إلى اليمين (أو أكثر)، فلا يوجد عنصر «تالٍ» واحد. وهذا التفرّع هو ما يجعل الشجرة غير خطية.

4مصطلحات الشجرة — تشريح الشجرة

لنسمِّ أجزاء الشجرة. مرّر المؤشر فوق أي عقدة أدناه لتتعرّف على اسمها.

👈 انقر على أي عقدة لتتعرّف على دورها

6قياس الشجرة — الارتفاع والعمق

كيف نقيس «حجم» الشجرة؟ نحن لا نستخدم الطول كما في المصفوفة أو القائمة المرتبطة، بل نستخدم الارتفاع والعمق.

📈 ارتفاع الشجرة

ارتفاع الشجرة هو عدد الحواف على أطول مسار من الجذر إلى أي ورقة.

💡 احسب الحواف، لا العقد!

📈 عمق العقدة

عمق العقدة هو عدد الحواف من الجذر إلى تلك العقدة.

عمق الجذر يساوي دائمًا 0.

🎯 مثال: كم يبلغ الارتفاع؟

انقر على «تتبّع الارتفاع» في كل شجرة لترى أطول مسار مظلّلًا باللون الأحمر.

🔑 قواعد الارتفاع

  • الشجرة التي تتكوّن من الجذر فقط (عقدة واحدة) ارتفاعها = 0
  • الارتفاع = عدد الحواف على أطول مسار من الجذر إلى ورقة
  • الارتفاع = (عدد العقد على أطول مسار) − 1
  • عمق الجذر يساوي دائمًا 0
  • ارتفاع أي عقدة ورقية يساوي 0

7لماذا تُعدّ الشجرة هيكل بيانات منطقيًا؟

نقول إن الشجرة هيكل بيانات منطقي؛ أي أن شكلها تحدّده قواعد وقيود، لا الطريقة التي تصادف أن تُرتَّب بها البيانات في الذاكرة الفعلية. وأهم قاعدة هي: يجب ألا تحتوي الشجرة على أي دورة (Cycle).

🔑 قواعد الشجرة — ما الذي يجعلها شجرة؟

  • يوجد جذر واحد بالضبط
  • لكل عقدة (عدا الجذر) أب واحد بالضبط
  • لا توجد دورات (لا يوجد مسار من عقدة يعود إليها نفسها)
  • الشجرة متصلة (يوجد مسار بين أي عقدتين)

إذا خُرقت أي قاعدة من هذه القواعد، فهي ليست شجرة — بل تصبح مخططًا عامًا.

9الشجرة الثنائية — قلب الأشجار في علوم الحاسب

📚 التعريف

الشجرة الثنائية هي هيكل بيانات شجري يكون لكل عقدة فيه ابنان على الأكثر، يُسمّيان الابن الأيسر والابن الأيمن. ويوجد جذر واحد بالضبط، وكل ابن هو بدوره شجرة ثنائية (أو فارغ).

💬 خصائص الشجرة الثنائية

  • تحتوي كل عقدة على: قيمة بيانات، ومرجع إلى الابن الأيسر، ومرجع إلى الابن الأيمن
  • يمكن أن يكون أيٌّ من الابنين null (فارغًا) — فقد يكون للعقدة 0 أو 1 أو 2 من الأبناء
  • الموضعان الأيسر والأيمن متمايزان — فالابن الأيسر يختلف عن الابن الأيمن حتى لو تساوت القيم

💻 بنية العقدة في جافا (Java)

class Node {
    int data;            // the value stored
    Node left;           // reference to left child
    Node right;          // reference to right child

    Node(int val) {
        data = val;
        left = null;      // no left child initially
        right = null;     // no right child initially
    }
}

10مستويات الشجرة والحد الأقصى لعدد العقد

في الشجرة الثنائية، تُنظَّم العقد في مستويات (Levels)؛ فالجذر في المستوى 0، وأبناؤه في المستوى 1، وأبناء أبنائه في المستوى 2، وهكذا.

الصيغة: الحد الأقصى لعدد العقد في المستوى i هو 2i
  • المستوى 0 (الجذر): عقدة 20 = 1 على الأكثر
  • المستوى 1: 21 = 2 عقدة على الأكثر
  • المستوى 2: 22 = 4 عقد على الأكثر
  • المستوى 3: 23 = 8 عقد على الأكثر
  • المستوى i: 2i عقدة على الأكثر

🎮 مستكشف المستويات التفاعلي

انقر على زر أحد المستويات لتظليل جميع العقد في ذلك المستوى ومعرفة الحد الأقصى لعددها.

المستوى 0: الحد الأقصى للعقد = 20 = 1  |  الجذر هو العقدة الوحيدة في هذا المستوى.
المستوى (i)الحد الأقصى للعقد = 2iأمثلة على العقد
020 = 18
121 = 24, 11
222 = 42, 6, 10, 13
323 = 81, 3, 5, 7, 9, 12, 14 (معروض 7، والحد الأقصى 8)

11الأشجار الفرعية

الشجرة الفرعية (Subtree) هي شجرة أصغر تتكوّن من أي عقدة في الشجرة مع جميع سلائلها. وكل عقدة في الشجرة هي جذر لشجرتها الفرعية الخاصة!

📚 التعريف

الشجرة الفرعية التي جذرها العقدة X تتكوّن من العقدة X وجميع سلائلها (الأبناء، وأبناء الأبناء، إلخ). وبحسب التعريف، فالشجرة الفرعية هي بحد ذاتها شجرة ثنائية صحيحة.

👈 انقر على عقدة لتظليل شجرتها الفرعية

انقر على أحد الأزرار لترى شجرة فرعية مظلّلة.

12الشجرة الثنائية الممتلئة

📚 التعريف

الشجرة الثنائية الممتلئة (Full Binary Tree) هي شجرة ثنائية يكون لكل عقدة فيها إما 0 أبناء (ورقة) أو ابنان (أيسر وأيمن معًا). ولا توجد عقدة لها ابن واحد فقط.

13الشجرة الثنائية الكاملة

📚 التعريف

الشجرة الثنائية الكاملة (Complete Binary Tree) هي شجرة ثنائية تتحقق فيها الشروط الآتية:
1. جميع المستويات مملوءة بالكامل باستثناء المستوى الأخير على الأرجح.
2. تكون جميع عقد المستوى الأخير في أقصى اليسار قدر الإمكان.

📊 مستكشف الشجرة الكاملة التفاعلي مستوىً بمستوى

انقر على أحد الأمثلة لترى التحليل مستوىً بمستوى. يعرض كل مستوى سعته (2i)، والمواضع المملوءة، وما إذا كانت قاعدة الملء من اليسار إلى اليمين متحققة.

🎮 اختبار — كاملة أم لا؟

تأمّل وصف كل شجرة وقرّر:

❓ شجرة فيها 6 عقد. للجذر ابنان، وللابن الأيسر ابنان، وللابن الأيمن ابن واحد (أيسر فقط). هل هذه الشجرة كاملة؟
نعم، كاملة
لا، ليست كاملة

14اجتياز الشجرة

كيف نزور كل عقدة في الشجرة؟ في المصفوفة أو القائمة المرتبطة نمرّ على العناصر واحدًا تلو الآخر بالترتيب. أما في الشجرة فهناك طرق متعددة للاجتياز، ونسمّيها خوارزميات الاجتياز (Traversal Algorithms).

📲 البحث بالعمق أولًا (Depth-First Search – DFS)

انزل إلى أعمق نقطة ممكنة قبل التراجع. وله ثلاثة أشكال:

  • الاجتياز القبلي (Pre-order) (الجذر، الأيسر، الأيمن)
  • الاجتياز البيني (In-order) (الأيسر، الجذر، الأيمن)
  • الاجتياز البعدي (Post-order) (الأيسر، الأيمن، الجذر)

🌐 البحث بالعرض أولًا (Breadth-First Search – BFS)

زُر جميع العقد في كل مستوى قبل النزول أعمق. ويُسمّى أيضًا الاجتياز حسب المستويات (Level-Order).

يستخدم طابورًا لمعالجة العقد مستوىً بمستوى.

💡 كيف تتذكّر: فكرة «الزيارات الثلاث»

تخيّل أنك تمشي عبر الشجرة. في كل مرة تمرّ فيها بعقدة، احسب الزيارة:

  • الزيارة الأولى (الوصول) ← القبلي — زُر الجذر عندما تصل إليه
  • الزيارة الثانية (العودة من اليسار) ← البيني — زُره عندما تعود من الشجرة الفرعية اليسرى
  • الزيارة الثالثة (العودة من اليمين) ← البعدي — زُره عندما تعود من الشجرة الفرعية اليمنى

الاجتياز القبلي

الجذر ← الأيسر ← الأيمن

زُر الجذر أولًا، ثم اجتز الشجرة الفرعية اليسرى استدعاءً ذاتيًا، ثم الشجرة الفرعية اليمنى.

يُستخدم في: نسخ الشجرة، والترميز البادئ (Prefix)

الاجتياز البيني

الأيسر ← الجذر ← الأيمن

اجتز الشجرة الفرعية اليسرى أولًا، ثم زُر الجذر، ثم الشجرة الفرعية اليمنى.

يُستخدم في: يُعطي ترتيبًا مفروزًا في شجرة البحث الثنائية (BST)!

الاجتياز البعدي

الأيسر ← الأيمن ← الجذر

اجتز الأيسر أولًا، ثم الأيمن، ثم زُر الجذر أخيرًا.

يُستخدم في: حذف الشجرة، والترميز اللاحق (Postfix)

🎮 محاكي الاجتياز التفاعلي

افتح المحاكي المخصّص لترى كل اجتياز خطوة بخطوة، مع زيارات العقد الفارغة (null)، ومفهوم الزيارات الثلاث، ونتائج الاجتياز القبلي والبيني والبعدي في آنٍ واحد، ومُصوِّر لطابور BFS.

◀ افتح محاكي اجتياز الشجرة

يعرض DFS (القبلي/البيني/البعدي) مع زيارات null وعدد الزيارات، وBFS مع حالة الطابور

🌐 البحث بالعرض أولًا (حسب المستويات) — كيف يعمل؟

يستخدم BFS هيكل بيانات الطابور. والخوارزمية كالآتي:

  1. البداية: أدخل الجذر في الطابور
  2. ما دام الطابور غير فارغ:
    1. أخرج العقدة الأمامية من الطابور وزُرها
    2. أدخل ابنها الأيسر في الطابور (إن وُجد)
    3. أدخل ابنها الأيمن في الطابور (إن وُجد)

وهذا يضمن أن نزور العقد مستوىً بمستوى، من اليسار إلى اليمين.

💻 شيفرة جافا لجميع أنواع الاجتياز

// Pre-order: Root → Left → Right
void preOrder(Node node) {
    if (node == null) return;
    System.out.print(node.data + " "); // visit ROOT first
    preOrder(node.left);
    preOrder(node.right);
}

// In-order: Left → Root → Right
void inOrder(Node node) {
    if (node == null) return;
    inOrder(node.left);
    System.out.print(node.data + " "); // visit ROOT in middle
    inOrder(node.right);
}

// Post-order: Left → Right → Root
void postOrder(Node node) {
    if (node == null) return;
    postOrder(node.left);
    postOrder(node.right);
    System.out.print(node.data + " "); // visit ROOT last
}

// Level-order (BFS): using a Queue
void levelOrder(Node root) {
    if (root == null) return;
    Queue<Node> queue = new LinkedList<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        Node n = queue.poll();
        System.out.print(n.data + " ");
        if (n.left != null) queue.add(n.left);
        if (n.right != null) queue.add(n.right);
    }
}
