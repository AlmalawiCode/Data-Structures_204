Q1 Linked-List Concepts (Multiple Choice) EASY CLO 7SO-2 6 marks · 1 each

Circle the single best answer for each item.

1. In a singly linked list, each node stores:

  (a) only the data value    (b) data and a reference to the next node    (c) data + references to both next and previous    (d) data + a reference to the head

2. Given only the head, which operation on a singly linked list is O(1)?

  (a) inserting a new node at the front    (b) inserting at the end    (c) deleting the last node    (d) searching for a value

3. In a doubly linked list, each node has references to:

  (a) the next node only    (b) the previous node only    (c) both the next and the previous nodes    (d) the head and the tail

4. In a circular singly linked list, the next field of the last node points to:

  (a) null    (b) itself    (c) the first node (head)    (d) the second node

5. To delete the last node of a singly linked list that has no tail pointer, you must first:

  (a) do nothing — it is O(1)    (b) traverse to the second-last node, so it costs O(n)    (c) reverse the list    (d) move the head

6. A key advantage of a linked list over an array is:

  (a) constant-time random access by index    (b) uses less memory per element    (c) grows/shrinks dynamically; insert/delete without shifting elements    (d) better cache locality

Model Answer — Q1

1: (b)   2: (a)   3: (c)   4: (c)   5: (b)   6: (c)

1 mark each. (2) front-insertion only rewires head; end-insertion needs a full traversal → O(n).

Q4 Write a Method — Maximum Value in the List MEDIUM CLO 7SO-2 10 marks

Use the standard singly linked list declaration:

class ll_node {    int data;    ll_node next;}

Write a Java method  public static int exam04(ll_node head)  that returns the largest data value stored in the list. If the list is empty (head == null), return -1.

Worked example. For the list below the method must return 50.
head 12next 45next 7next 50next 8next null
Write your complete method:
Model Answer — Q4
public static int exam04(ll_node head) {    if (head == null) {                // empty-list guard        return -1;    }    int max = head.data;              // first value is the running max    ll_node hp = head.next;           // help pointer starts at 2nd node    while (hp != null) {        if (hp.data > max) {            max = hp.data;        }        hp = hp.next;    }    return max;}

Rubric: empty guard 2 · init max 2 · correct traversal loop 3 · compare/update 2 · return 1.

Q5 Write a Method — Delete All Negative Nodes HARD CLO 7SO-2 12 marks

Write  public static ll_node exam05(ll_node head)  that deletes every node whose data is negative and returns the head of the resulting list. Your solution must correctly handle: deleting one or more nodes at the front, an empty list, and a list that becomes empty.

Worked example.
head -3next 8next -1next 4next -7next 6next null
becomes  head → 8 → 4 → 6 → null
Write your complete method:
Model Answer — Q5
public static ll_node exam05(ll_node head) {    // 1) strip leading negative nodes    while (head != null && head.data < 0) {        head = head.next;    }    if (head == null) {                // list emptied out        return null;    }    // 2) now head is safe; unlink negatives with a trailing pointer    ll_node hp = head;    while (hp.next != null) {        if (hp.next.data < 0) {            hp.next = hp.next.next;    // bypass the negative node        } else {            hp = hp.next;              // only advance when kept        }    }    return head;}

Rubric: leading-negatives loop 3 · emptied guard 2 · traversal with hp.next 3 · unlink (bypass) 2 · conditional advance 1 · return 1. Common bug: advancing hp after a delete skips the next node.

Q6 Write a Method — Append a Node Holding the Sum MEDIUM CLO 7SO-2 10 marks

Write  public static void exam06(ll_node head)  that appends one new node at the end of the list whose data equals the sum of all existing data values. You may assume the list is not empty (head != null).

Worked example.  head → 2 → 5 → 3 → null   becomes   head → 2 → 5 → 3 → 10 → null  (2+5+3 = 10).

Hint: a single traversal can both accumulate the sum and find the last node.

Write your complete method:
Model Answer — Q6
public static void exam06(ll_node head) {    int sum = 0;    ll_node hp = head;    while (hp.next != null) {   // stop at the LAST node        sum += hp.data;        hp = hp.next;    }    sum += hp.data;              // add the last node's data too    ll_node n = new ll_node();  // build the new tail node    n.data = sum;    n.next = null;    hp.next = n;                 // link it after the old last node}

Rubric: init sum/hp 2 · loop to last node 3 · include last data 1 · create node + set data/next 2 · link at end 2. Deduct if the loop runs off the end (NullPointerException).

Q7 Frequency Counting into a Provided Array MEDIUM CLO 7SO-2 8 marks

Every node's data is a single digit (0–9). Write  public static void exam07(ll_node head, int[] freq)  where freq has length 10. The method must set freq[d] to the number of nodes whose data equals d.

Worked example.
head 3next 1next 3next 7next 3next 1next null
After the call, freq is:
0123456789
0203000100
Write your complete method:
Model Answer — Q7
public static void exam07(ll_node head, int[] freq) {    ll_node hp = head;    while (hp != null) {        freq[hp.data]++;     // data is a valid index 0..9        hp = hp.next;    }}

Rubric: help pointer 1 · loop 3 · use data as index & increment 3 · advance 1. (No need to clear freq — assume it starts at 0.)

Q8 Recursive Method on a Linked List HARD CLO 8SO-2 10 marks

Write  public static int exam08(ll_node head)  that returns the sum of the data values of nodes at even positions, counting the head as position 0 (so positions 0, 2, 4, … are added). An empty list returns 0.

Note: you will not get points unless you use recursion (no loops).

Worked example.  head → 5 → 8 → 3 → 4 → 9 → null  → positions 0,2,4 hold 5, 3, 9 → returns 17.

Hint: think of a helper that recurses two nodes at a time, or pass the parity along.

Write your complete method (add a helper if you wish):
Model Answer — Q8
public static int exam08(ll_node head) {    if (head == null) {                // base case        return 0;    }    if (head.next == null) {           // single node left        return head.data;    }    // take current (even pos), skip next (odd pos), recurse past both    return head.data + exam08(head.next.next);}

Rubric: base case(s) 3 · take current node's data 2 · skip two nodes in the recursive call 4 · overall correctness 1. Any correct recursion (e.g. a parity-flag helper) earns full marks; a loop-based answer earns 0.

Q10 Circular Singly Linked List — Count the Nodes MEDIUM CLO 7SO-2 6 marks

In a circular singly linked list the last node's next points back to head (there is no null):

head 10next 20next 30next  ↶ back to head

Write  public static int exam10(ll_node head)  that returns the number of nodes. It must return 0 for an empty list (head == null) and must not loop forever.

Write your complete method:
Model Answer — Q10
public static int exam10(ll_node head) {    if (head == null) {        return 0;    }    int count = 1;             // count head, then walk until we return to it    ll_node hp = head.next;    while (hp != head) {        count++;        hp = hp.next;    }    return count;}

Rubric: empty guard 2 · start count at 1 / hp at head.next 2 · loop condition hp != head (not hp != null) 2. Using hp != null loops forever — key testing point.
