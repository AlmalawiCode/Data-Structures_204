السؤال 11 متوسط

إيجاد العقدة الوسطى

اكتب دالة (method) تجد العقدة (node) الوسطى في قائمة مرتبطة أحادية (singly linked list) وتعيدها، باستخدام تقنية المؤشر البطيء والمؤشر السريع (slow and fast pointer technique) (وتُعرف أيضًا بطريقة السلحفاة والأرنب (tortoise and hare)). إذا كان عدد العقد في القائمة زوجيًا، فأعد العقدة الوسطى الثانية.

Node findMiddle(Node head)
مثال: إيجاد العقدة الوسطى head ↓ 1next → 2next → 3next → 4next → 5next → null

▲ العقدة الوسطى (القيمة المُعادة)

الحل: تقنية المؤشر البطيء والمؤشر السريع

استخدم مؤشرين (pointers): المؤشر slow يتقدم خطوة واحدة في كل مرة، والمؤشر fast يتقدم خطوتين في كل مرة. عندما يصل المؤشر السريع إلى نهاية القائمة (أو إلى null)، يكون المؤشر البطيء عند العقدة الوسطى تمامًا. تنجح هذه الطريقة لأن fast يجتاز القائمة بضعف السرعة، فعندما ينتهي يكون slow قد قطع نصف المسافة بالضبط.

شيفرة الحل
public Node findMiddle(Node head) {
    Node slow = head;
    Node fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}

تتبّع المثال [1, 2, 3, 4, 5]:
الخطوة 0: slow = 1, fast = 1
الخطوة 1: slow = 2, fast = 3
الخطوة 2: slow = 3, fast = 5
الآن fast.next == null، لذا تنتهي الحلقة. يشير slow إلى العقدة 3 (العقدة الوسطى).

التعقيد الزمني (Time Complexity): O(n) - مرور واحد على القائمة
التعقيد المكاني (Space Complexity): O(1) - نستخدم متغيرَي مؤشر فقط
السؤال 12 متوسط

اكتشاف الدورة (خوارزمية فلويد)

اكتب دالة تكتشف ما إذا كانت القائمة المرتبطة الأحادية تحتوي على دورة (cycle) باستخدام خوارزمية فلويد لاكتشاف الدورات (Floyd's Cycle Detection Algorithm). توجد الدورة إذا كان المؤشر next لإحدى العقد يشير عائدًا إلى عقدة سابقة في القائمة، مما يُنشئ حلقة لا نهائية.

boolean hasCycle(Node head)
مثال: قائمة مرتبطة فيها دورة (العقدة 4 تشير عائدةً إلى العقدة 3) head ↓ 1next → 2next → 3next → 4next ↵ عودة إلى العقدة 3

الحل: خوارزمية فلويد لاكتشاف الدورات (السلحفاة والأرنب)

استخدم مؤشرين يتحركان بسرعتين مختلفتين. المؤشر slow يتقدم عقدة واحدة في كل مرة، بينما يتقدم المؤشر fast عقدتين في كل مرة. إذا وُجدت دورة، فإن المؤشر السريع سيلحق بالمؤشر البطيء في النهاية "ويسبقه بلفة" فيلتقيان عند العقدة نفسها. وإذا لم توجد دورة، فسيصل المؤشر السريع إلى null.

شيفرة الحل
public boolean hasCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

لماذا تنجح؟ تخيّل عدّاءَين على مضمار دائري؛ العدّاء الأسرع سيلحق دائمًا بالأبطأ. في كل تكرار تقل المسافة بينهما بمقدار عقدة واحدة، فلا بد أن يلتقيا في النهاية إذا وُجدت دورة. وإذا لم توجد دورة، يصل المؤشر السريع بأمان إلى null ونعيد false.

التعقيد الزمني: O(n) - في أسوأ حالة (worst case) يجتاز fast الدورة مرتين على الأكثر
التعقيد المكاني (Space Complexity): O(1) - نستخدم متغيرَي مؤشر فقط
السؤال 13 متوسط

إيجاد العقدة رقم N من النهاية

اكتب دالة تعيد العقدة رقم N من نهاية قائمة مرتبطة أحادية في مرور واحد (single pass). على سبيل المثال، إذا كانت n = 2، فأعد العقدة الثانية من النهاية.

Node nthFromEnd(Node head, int n)
مثال: إيجاد العقدة الثانية من النهاية (n = 2) head ↓ 10next → 20next → 30next → 40next → 50next → null

▲ الثانية من النهاية (الإجابة: 40)

الحل: تقنية المؤشرين مع فجوة ثابتة

استخدم مؤشرين بينهما فجوة مقدارها n من العقد. أولًا، حرّك المؤشر fast n خطوات إلى الأمام. ثم حرّك المؤشرين معًا خطوة واحدة في كل مرة. عندما يصل fast إلى null، يكون slow عند العقدة رقم n من النهاية. الفكرة الأساسية أن الفجوة بين المؤشرين تبقى دائمًا n عقدة بالضبط.

شيفرة الحل
public Node nthFromEnd(Node head, int n) {
    Node fast = head;
    Node slow = head;

    // Move fast pointer n steps ahead
    for (int i = 0; i < n; i++) {
        if (fast == null) return null; // n is larger than list size
        fast = fast.next;
    }

    // Move both pointers until fast reaches the end
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }

    return slow;
}

التتبّع عند n = 2 على القائمة [10, 20, 30, 40, 50]:
بعد تحريك fast خطوتين: fast = 30, slow = 10
الخطوة 1: fast = 40, slow = 20
الخطوة 2: fast = 50, slow = 30
الخطوة 3: fast = null, slow = 40
النتيجة: يشير slow إلى 40، وهي العقدة الثانية من النهاية.

التعقيد الزمني (Time Complexity): O(n) - مرور واحد على القائمة
التعقيد المكاني (Space Complexity): O(1) - نستخدم متغيرَي مؤشر فقط
السؤال 14 متوسط

حذف التكرارات من قائمة مرتبة

اكتب دالة تحذف جميع القيم المكررة (duplicates) من قائمة مرتبطة أحادية مرتبة (sorted)، بحيث يظهر كل عنصر مرة واحدة فقط. ويجب أن تبقى القائمة مرتبة بعد الحذف.

Node removeDuplicates(Node head)
قبل: قائمة مرتبة تحتوي على تكرارات head ↓ 1next → 1next → 2next → 3next → 3next → null
بعد: حذف التكرارات head ↓ 1next → 2next → 3next → null

الحل: تخطّي العقد المكررة

بما أن القائمة مرتبة، فإن جميع التكرارات تكون متجاورة. اجتز (traverse) القائمة، ولكل عقدة قارن قيمتها بقيمة العقدة التالية. إذا تساوتا، فتخطَّ العقدة التالية بتحديث المؤشر next للعقدة الحالية. وإلا فانتقل إلى العقدة التالية.

شيفرة الحل
public Node removeDuplicates(Node head) {
    Node current = head;
    while (current != null && current.next != null) {
        if (current.data == current.next.data) {
            // Skip the duplicate node
            current.next = current.next.next;
        } else {
            // Move to next distinct node
            current = current.next;
        }
    }
    return head;
}

الفكرة الأساسية: عندما نجد تكرارًا، لا نُقدّم المؤشر current. والسبب أنه قد يوجد أكثر من تكرارين متتاليين (مثل 1 → 1 → 1). ولا نتقدم إلا عندما تختلف current.data عن current.next.data.

التعقيد الزمني (Time Complexity): O(n) - مرور واحد على القائمة
التعقيد المكاني: O(1) - تعديل في المكان دون مساحة إضافية
السؤال 15 متوسط

دمج قائمتين مرتبتين

اكتب دالة تدمج (merge) قائمتين مرتبطتين أحاديتين مرتبتين في قائمة مرتبطة واحدة مرتبة. ويجب أن تُبنى القائمة المدمجة بوصل عقد القائمتين المُدخلتين معًا.

Node mergeSorted(Node l1, Node l2)
القائمة 1 (مرتبة): 1next → 3next → 5next → null
القائمة 2 (مرتبة): 2next → 4next → 6next → null
النتيجة بعد الدمج (مرتبة): 1next → 2next → 3next → 4next → 5next → 6next → null

الحل: تقنية العقدة الوهمية

أنشئ عقدة وهمية (dummy node) لتبسيط الحالات الطرفية (edge cases) (فهي تُغنينا عن معالجة خاصة لرأس القائمة (head)). استخدم مؤشر ذيل (tail) لبناء القائمة المدمجة. قارن بين رأسَي القائمتين، وألحق الأصغر منهما بالذيل، ثم قدّم مؤشر تلك القائمة. استمر حتى تنفد إحدى القائمتين، ثم ألحق ما تبقّى من القائمة الأخرى.

شيفرة الحل
public Node mergeSorted(Node l1, Node l2) {
    // Dummy node acts as a placeholder for the result head
    Node dummy = new Node(0);
    Node tail = dummy;

    while (l1 != null && l2 != null) {
        if (l1.data <= l2.data) {
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }

    // Attach the remaining nodes
    tail.next = (l1 != null) ? l1 : l2;

    return dummy.next;
}

لماذا نستخدم عقدة وهمية؟ بدونها تحتاج إلى منطق إضافي لتحديد العقدة التي ستصبح رأس القائمة المدمجة. توفّر العقدة الوهمية نقطة بداية ثابتة. ونعيد dummy.next لتخطّي العقدة الوهمية والحصول على الرأس الفعلي للقائمة المدمجة.

التعقيد الزمني: O(n + m) - حيث n و m طولا القائمتين
التعقيد المكاني: O(1) - نعيد استخدام العقد الموجودة ولا ننشئ عقدًا جديدة
السؤال 16 متوسط

التحقق مما إذا كانت القائمة المرتبطة متناظرة (Palindrome)

اكتب دالة تتحقق مما إذا كانت القائمة المرتبطة الأحادية تُقرأ بالشكل نفسه من الأمام ومن الخلف (أي أنها متناظرة (palindrome)). حُلّها بزمن O(n) ومساحة O(1).

boolean isPalindrome(Node head)
مثال: قائمة متناظرة (تُقرأ بالشكل نفسه من الأمام ومن الخلف) head ↓ 1next → 2next → 3next → 2next → 1next → null

متناظرة: 1 → 2 → 3 → 2 → 1

الحل: إيجاد المنتصف، ثم عكس النصف الثاني، ثم المقارنة

يجمع هذا الحل بين ثلاث تقنيات للقوائم المرتبطة:
1. إيجاد العقدة الوسطى باستخدام المؤشرين slow/fast.
2. عكس النصف الثاني من القائمة في مكانه (in-place).
3. مقارنة النصف الأول بالنصف الثاني المعكوس عقدةً بعقدة.

شيفرة الحل
public boolean isPalindrome(Node head) {
    if (head == null || head.next == null) return true;

    // Step 1: Find the middle
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // Step 2: Reverse the second half
    Node prev = null;
    Node curr = slow;
    while (curr != null) {
        Node next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    // Step 3: Compare both halves
    Node left = head;
    Node right = prev; // prev is now head of reversed second half
    while (right != null) {
        if (left.data != right.data) return false;
        left = left.next;
        right = right.next;
    }

    return true;
}

للقائمة [1, 2, 3, 2, 1]:
المنتصف = العقدة 3. النصف الثاني بعد العكس = [1, 2, 3].
المقارنة: 1==1, 2==2, 3==3 — جميعها متطابقة، إذن القائمة متناظرة.
ملاحظة: هذا الحل يعدّل القائمة الأصلية. في الشيفرة الإنتاجية قد ترغب في استعادة القائمة بعكس النصف الثاني مرة أخرى بعد المقارنة.

التعقيد الزمني: O(n) - ثلاثة مرورات (إيجاد المنتصف، العكس، المقارنة)
التعقيد المكاني: O(1) - يتم العكس في المكان
السؤال 17 صعب

تبديل العقد في أزواج

اكتب دالة تبدّل كل عقدتين متجاورتين في قائمة مرتبطة أحادية، وتعيد الرأس الجديد. يجب أن تبدّل العقد نفسها، لا قيمها فقط.

Node swapPairs(Node head)
قبل: القائمة الأصلية head ↓ 1next → 2next → 3next → 4next → null
بعد: تبديل العقد في أزواج head ↓ 2next → 1next → 4next → 3next → null

الحل: تبديل الأزواج تكراريًا باستخدام عقدة وهمية

استخدم عقدة وهمية قبل الرأس لتبسيط التعامل مع المؤشرات. لكل زوج من العقد (first و second)، أعد ترتيب المؤشرات بحيث يصبح prev → second → first → rest. ثم قدّم prev إلى العقدة first (التي أصبحت الآن بعد second) وتابع مع الزوج التالي.

شيفرة الحل
public Node swapPairs(Node head) {
    Node dummy = new Node(0);
    dummy.next = head;
    Node prev = dummy;

    while (prev.next != null && prev.next.next != null) {
        Node first = prev.next;
        Node second = prev.next.next;

        // Perform the swap
        first.next = second.next;
        second.next = first;
        prev.next = second;

        // Move prev to the next pair
        prev = first;
    }

    return dummy.next;
}

إعادة ترتيب المؤشرات لكل زوج:
المُعطى: prev → first → second → rest
الخطوة 1: first.next = rest (أصبح first يشير إلى ما بعد second)
الخطوة 2: second.next = first (أصبح second يشير إلى first)
الخطوة 3: prev.next = second (أصبح prev يشير إلى second)
النتيجة: prev → second → first → rest

التعقيد الزمني: O(n) - نزور كل عقدة مرة واحدة بالضبط
التعقيد المكاني: O(1) - متغيرات مؤشرات فقط، دون هياكل بيانات إضافية
السؤال 19 صعب

تحويل قائمة مرتبطة أحادية إلى قائمة مرتبطة مزدوجة

بافتراض أن لديك قائمة مرتبطة أحادية (Singly Linked List) بمؤشر head، اكتب دالة تحوّلها إلى قائمة مرتبطة مزدوجة (Doubly Linked List) بمؤشر dHead. يجب أن تحتوي كل عقدة في القائمة الجديدة على المؤشرين next وprev معًا. استخدم صنفًا (class) مستقلًا باسم DNode يحتوي على الحقول data و next و prev.

DNode convertToDoubly(Node head)
بافتراض أن لديك هذه القائمة الأحادية (SLL) بالمؤشر head:
head Anext → Bnext → Cnext → null
حوّلها إلى هذه القائمة المزدوجة (DLL) بالمؤشر dHead:

الحل: إنشاء عقد DNode جديدة بكلا المؤشرين

اجتز القائمة المرتبطة الأحادية. لكل عقدة، أنشئ عقدة DNode جديدة بالبيانات نفسها. اجعل المؤشر prev للعقدة الجديدة يشير إلى عقدة DNode التي أُنشئت قبلها، واجعل المؤشر next لعقدة DNode السابقة يشير إلى العقدة الجديدة. واحتفظ برأس القائمة المرتبطة المزدوجة لإعادته.

شيفرة الحل
// Doubly linked list node class
class DNode {
    int data;
    DNode next;
    DNode prev;

    DNode(int data) {
        this.data = data;
        this.next = null;
        this.prev = null;
    }
}

public DNode convertToDoubly(Node head) {
    if (head == null) return null;

    // Create the head of the doubly linked list
    DNode dHead = new DNode(head.data);
    DNode dCurrent = dHead;
    Node current = head.next;

    while (current != null) {
        // Create new DNode
        DNode newNode = new DNode(current.data);

        // Set forward and backward pointers
        dCurrent.next = newNode;
        newNode.prev = dCurrent;

        // Advance both pointers
        dCurrent = newNode;
        current = current.next;
    }

    return dHead;
}

خطوة بخطوة للقائمة [A, B, C]:
1. أنشئ DNode(A) واجعلها dHead. dCurrent = DNode(A).
2. أنشئ DNode(B). اجعل DNode(A).next = DNode(B)، وDNode(B).prev = DNode(A).
3. أنشئ DNode(C). اجعل DNode(B).next = DNode(C)، وDNode(C).prev = DNode(B).
النتيجة: null ← A ↔ B ↔ C → null

التعقيد الزمني: O(n) - اجتياز واحد للقائمة المرتبطة الأحادية
التعقيد المكاني: O(n) - إنشاء n كائنًا جديدًا من نوع DNode
