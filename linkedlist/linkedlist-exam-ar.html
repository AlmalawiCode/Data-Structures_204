س1 مفاهيم القوائم المرتبطة (اختيار من متعدد) سهل CLO 7SO-2 6 درجات · درجة لكل فقرة

ضع دائرة حول أفضل إجابة واحدة لكل فقرة.

1. في القائمة المرتبطة الأحادية (Singly Linked List)، تخزّن كل عقدة:

  (أ) قيمة البيانات فقط    (ب) البيانات ومرجعاً إلى العقدة التالية    (ج) البيانات + مرجعين إلى العقدتين التالية والسابقة    (د) البيانات + مرجعاً إلى رأس القائمة

2. إذا لم يُعطَ إلا head، فأيّ العمليات الآتية على القائمة المرتبطة الأحادية تكون O(1)؟

  (أ) إدراج عقدة جديدة في بداية القائمة    (ب) الإدراج في النهاية    (ج) حذف العقدة الأخيرة    (د) البحث عن قيمة

3. في القائمة المرتبطة المزدوجة (Doubly Linked List)، تحتوي كل عقدة على مراجع إلى:

  (أ) العقدة التالية فقط    (ب) العقدة السابقة فقط    (ج) العقدتين التالية والسابقة كلتيهما    (د) رأس القائمة (Head) وذيل القائمة (Tail)

4. في القائمة المرتبطة الدائرية الأحادية (Circular Singly Linked List)، يشير الحقل next في العقدة الأخيرة إلى:

  (أ) null    (ب) نفسها    (ج) العقدة الأولى (head)    (د) العقدة الثانية

5. لحذف العقدة الأخيرة من قائمة مرتبطة أحادية ليس لها مرجع ذيل (Tail Pointer)، يجب أولاً:

  (أ) لا شيء — فالعملية O(1)    (ب) الاجتياز حتى العقدة قبل الأخيرة، لذا تكلّف O(n)    (ج) عكس القائمة    (د) تحريك رأس القائمة

6. من المزايا الأساسية للقائمة المرتبطة مقارنةً بالمصفوفة:

  (أ) الوصول العشوائي بالفهرس (Index) في زمن ثابت    (ب) تستهلك ذاكرة أقل لكل عنصر    (ج) تكبر وتصغر ديناميكياً؛ ويتم الإدراج والحذف دون إزاحة العناصر    (د) محلية أفضل في الذاكرة المخبئية (Cache Locality)

1: (ب)   2: (أ)   3: (ج)   4: (ج)   5: (ب)   6: (ج)

س3 القائمة المرتبطة المزدوجة — تتبّع المراجع متوسط CLO 7SO-2 6 درجات · 1.5 لكل فقرة

لقائمة مرتبطة مزدوجة بتعريف العقدة الآتي:

class ll_node {    int data;    ll_node next;    ll_node prev;}
head p10n p20n p30n p40n p50n  ← tail

(head.prev == null وtail.next == null.)

اكتب القيمة الناتجة عن كل تعبير:

1.  head.next.next.next.data
2.  tail.prev.prev.data
3.  head.next.next.prev.data
4.  head.next.next.prev.prev.data
الإجابة النموذجية — س3

1: 10→20→30→40  |  2: 50→40→30  |  3: 10→20→30→(prev)20  |  4: 10→20→30→(prev)20→(prev)10

س4 اكتب دالة — القيمة العظمى في القائمة متوسط CLO 7SO-2 10 درجات

استخدم التعريف القياسي للقائمة المرتبطة الأحادية:

class ll_node {    int data;    ll_node next;}

اكتب دالة Java  public static int exam04(ll_node head)  تُرجع أكبر قيمة data مخزّنة في القائمة. إذا كانت القائمة فارغة (head == null)، فأرجِع -1.

مثال محلول. للقائمة أدناه يجب أن تُرجع الدالة 50.
head 12next 45next 7next 50next 8next null
اكتب دالتك كاملة:
الإجابة النموذجية — س4
public static int exam04(ll_node head) {    if (head == null) {                // حماية من القائمة الفارغة        return -1;    }    int max = head.data;              // القيمة الأولى هي القيمة العظمى الحالية    ll_node hp = head.next;           // المرجع المساعد يبدأ من العقدة الثانية    while (hp != null) {        if (hp.data > max) {            max = hp.data;        }        hp = hp.next;    }    return max;}

توزيع الدرجات: حماية القائمة الفارغة 2 · تهيئة max ‏2 · حلقة اجتياز صحيحة 3 · المقارنة/التحديث 2 · الإرجاع 1.

س5 اكتب دالة — حذف جميع العقد السالبة صعب CLO 7SO-2 12 درجة

اكتب  public static ll_node exam05(ll_node head)  التي تحذف كل عقدة قيمة data فيها سالبة وتُرجع رأس القائمة الناتجة. يجب أن يعالج حلّك بشكل صحيح: حذف عقدة أو أكثر في بداية القائمة، والقائمة الفارغة، والقائمة التي تصبح فارغة.

مثال محلول.
head -3next 8next -1next 4next -7next 6next null
تصبح  head → 8 → 4 → 6 → null
اكتب دالتك كاملة:
الإجابة النموذجية — س5
public static ll_node exam05(ll_node head) {    // 1) إزالة العقد السالبة في بداية القائمة    while (head != null && head.data < 0) {        head = head.next;    }    if (head == null) {                // أصبحت القائمة فارغة        return null;    }    // 2) أصبح head آمناً الآن؛ نفصل العقد السالبة بمرجع متأخر    ll_node hp = head;    while (hp.next != null) {        if (hp.next.data < 0) {            hp.next = hp.next.next;    // تخطّي العقدة السالبة        } else {            hp = hp.next;              // التقدّم فقط عند إبقاء العقدة        }    }    return head;}

توزيع الدرجات: حلقة العقد السالبة في البداية 3 · حماية القائمة التي فرغت 2 · الاجتياز باستخدام hp.next ‏3 · الفصل (التخطّي) 2 · التقدّم المشروط 1 · الإرجاع 1. خطأ شائع: تحريك hp بعد الحذف يتخطّى العقدة التالية.

س6 اكتب دالة — إلحاق عقدة تحمل المجموع متوسط CLO 7SO-2 10 درجات

اكتب  public static void exam06(ll_node head)  التي تُلحق عقدة جديدة واحدة في نهاية القائمة تساوي قيمة data فيها مجموع جميع قيم البيانات الموجودة. يمكنك افتراض أن القائمة ليست فارغة (head != null).

مثال محلول.  head → 2 → 5 → 3 → null   تصبح   head → 2 → 5 → 3 → 10 → null  (2+5+3 = 10).

تلميح: يمكن لاجتياز واحد أن يجمع المجموع ويجد العقدة الأخيرة معاً.

اكتب دالتك كاملة:
الإجابة النموذجية — س6
public static void exam06(ll_node head) {    int sum = 0;    ll_node hp = head;    while (hp.next != null) {   // التوقف عند العقدة الأخيرة        sum += hp.data;        hp = hp.next;    }    sum += hp.data;              // إضافة بيانات العقدة الأخيرة أيضاً    ll_node n = new ll_node();  // إنشاء عقدة الذيل الجديدة    n.data = sum;    n.next = null;    hp.next = n;                 // ربطها بعد العقدة الأخيرة القديمة}

توزيع الدرجات: تهيئة sum/hp ‏2 · حلقة حتى العقدة الأخيرة 3 · تضمين بيانات العقدة الأخيرة 1 · إنشاء العقدة + تعيين data/next ‏2 · الربط في النهاية 2. تُخصم درجات إذا تجاوزت الحلقة نهاية القائمة (NullPointerException).

س7 عدّ التكرارات في مصفوفة معطاة متوسط CLO 7SO-2 8 درجات

قيمة data في كل عقدة رقم واحد (0–9). اكتب  public static void exam07(ll_node head, int[] freq)  حيث طول freq يساوي 10. يجب أن تجعل الدالة freq[d] مساوياً لعدد العقد التي تساوي بياناتها d.

مثال محلول.
head 3next 1next 3next 7next 3next 1next null
بعد الاستدعاء، تصبح freq:
0123456789
0203000100
اكتب دالتك كاملة:
الإجابة النموذجية — س7
public static void exam07(ll_node head, int[] freq) {    ll_node hp = head;    while (hp != null) {        freq[hp.data]++;     // data فهرس صالح 0..9        hp = hp.next;    }}

توزيع الدرجات: المرجع المساعد 1 · الحلقة 3 · استخدام data فهرساً والزيادة 3 · التقدّم 1. (لا حاجة إلى تصفير freq — افترض أنها تبدأ بالقيمة 0.)

س8 دالة ذاتية الاستدعاء على قائمة مرتبطة صعب CLO 8SO-2 10 درجات

اكتب  public static int exam08(ll_node head)  التي تُرجع مجموع قيم البيانات في العقد الواقعة في المواضع الزوجية، مع اعتبار رأس القائمة في الموضع 0 (أي تُجمع المواضع 0، 2، 4، …). القائمة الفارغة تُرجع 0.

ملاحظة: لن تحصل على أي درجة ما لم تستخدم الاستدعاء الذاتي (بدون حلقات).

مثال محلول.  head → 5 → 8 → 3 → 4 → 9 → null  ← المواضع 0، 2، 4 تحمل 5، 3، 9 ← تُرجع 17.

تلميح: فكّر في دالة مساعدة تستدعي نفسها متقدّمةً عقدتين في كل مرة، أو مرّر زوجية الموضع مع الاستدعاء.

اكتب دالتك كاملة (أضف دالة مساعدة إن شئت):
الإجابة النموذجية — س8
public static int exam08(ll_node head) {    if (head == null) {                // الحالة الأساسية        return 0;    }    if (head.next == null) {           // بقيت عقدة واحدة        return head.data;    }    // خذ الحالية (موضع زوجي)، وتخطَّ التالية (موضع فردي)، واستدعِ بعدهما    return head.data + exam08(head.next.next);}

توزيع الدرجات: الحالة (الحالات) الأساسية (Base Case) ‏3 · أخذ بيانات العقدة الحالية 2 · تخطّي عقدتين في الاستدعاء الذاتي 4 · الصحة الإجمالية 1. أي حل ذاتي الاستدعاء صحيح (مثل دالة مساعدة بعلَم للزوجية) ينال الدرجة كاملة؛ والإجابة المعتمدة على الحلقات تنال 0.

س9 القائمة المرتبطة المزدوجة — الإدراج بين عقدتين متوسط CLO 7SO-2 6 درجات

س10 القائمة المرتبطة الدائرية الأحادية — عدّ العقد متوسط CLO 7SO-2 6 درجات

في القائمة المرتبطة الأحادية الدائرية (Circular Linked List) يشير next في العقدة الأخيرة عائداً إلى head (لا يوجد null):

head 10next 20next 30next  ↶ عودة إلى head

اكتب  public static int exam10(ll_node head)  التي تُرجع عدد العقد. يجب أن تُرجع 0 للقائمة الفارغة (head == null) وألّا تدخل في حلقة لا نهائية.

اكتب دالتك كاملة:
الإجابة النموذجية — س10
public static int exam10(ll_node head) {    if (head == null) {        return 0;    }    int count = 1;             // عُدّ head، ثم تقدّم حتى نعود إليه    ll_node hp = head.next;    while (hp != head) {        count++;        hp = hp.next;    }    return count;}

توزيع الدرجات: حماية القائمة الفارغة 2 · بدء count بالقيمة 1 و hp عند head.next ‏2 · شرط الحلقة hp != head (وليس hp != null) 2. استخدام hp != null يسبب حلقة لا نهائية — وهي نقطة الاختبار الأساسية.
