س1سهل
اجتياز (Traversal) قائمة مرتبطة أحادية (Singly Linked List) وطباعتها
اكتب دالة void printList(Node head) تطبع جميع عناصر قائمة مرتبطة أحادية مفصولةً بـ -> .
head 10next → 20next → 30next → null
المخرج المتوقع: 10 -> 20 -> 30 -> null

الحل:

كود الحل
public void printList(Node head) {
    Node current = head;
    while (current != null) {
        System.out.print(current.data + " -> ");
        current = current.next;
    }
    System.out.println("null");
}
الشرح: نستخدم مرجعاً (Pointer) باسم current يبدأ من head. نجتاز القائمة بتحريك current = current.next حتى نصل إلى null. التعقيد الزمني (Time Complexity): O(n)، التعقيد المكاني (Space Complexity): O(1).
س2سهل
عدّ العقد (Nodes) في قائمة مرتبطة
اكتب دالة int countNodes(Node head) تُرجع العدد الكلي للعقد.
head 5next → 12next → 7next → 3next → null
المخرج المتوقع: 4

الحل:

كود الحل
public int countNodes(Node head) {
    int count = 0;
    Node current = head;
    while (current != null) {
        count++;
        current = current.next;
    }
    return count;
}
الشرح: نهيّئ عدّاداً بالقيمة 0. نجتاز القائمة ونزيد العدّاد عند كل عقدة. الزمن: O(n)، المساحة: O(1).
س3سهل
الإدراج في البداية
اكتب دالة Node insertAtHead(Node head, int data) تُدرج عقدة جديدة في بداية القائمة.
قبل:
head 20next → 30next → null
بعد إدراج 10:
head 10next → 20next → 30next → null

الحل:

كود الحل
public Node insertAtHead(Node head, int data) {
    Node newNode = new Node(data);
    newNode.next = head;
    head = newNode;
    return head;
}
الشرح: أنشئ عقدة جديدة، واجعل next الخاص بها يشير إلى رأس القائمة (Head) الحالي، ثم حدّث head ليصبح العقدة الجديدة. الزمن: O(1)، المساحة: O(1).
س4سهل
الإدراج في النهاية
اكتب دالة Node insertAtEnd(Node head, int data) تُدرج عقدة جديدة في نهاية القائمة.
قبل:
head 10next → 20next → null
بعد إدراج 30:
head 10next → 20next → 30next → null

الحل:

كود الحل
public Node insertAtEnd(Node head, int data) {
    Node newNode = new Node(data);
    if (head == null) return newNode;
    Node current = head;
    while (current.next != null) {
        current = current.next;
    }
    current.next = newNode;
    return head;
}
الشرح: اجتز القائمة حتى آخر عقدة (حيث next == null)، ثم اجعل next الخاص بها يشير إلى العقدة الجديدة. الزمن: O(n)، المساحة: O(1).
س5سهل
البحث عن قيمة
اكتب دالة boolean search(Node head, int target) تُرجع true إذا كانت القيمة المستهدفة موجودة في القائمة.
head 4next → 8next → 15next → 23next → null
البحث عن 15 ← تُرجع true

الحل:

كود الحل
public boolean search(Node head, int target) {
    Node current = head;
    while (current != null) {
        if (current.data == target) return true;
        current = current.next;
    }
    return false;
}
الشرح: بحث خطي (Linear Search) عبر كل عقدة بمقارنة data مع target. الزمن: O(n)، المساحة: O(1).

حذف العقدة الأولى
اكتب دالة Node deleteFirst(Node head) تحذف العقدة الأولى وتُرجع رأس القائمة الجديد.
قبل:
head 10حذف → 20next → 30next → null
بعد:
head 20next → 30next → null

الحل:

كود الحل
public Node deleteFirst(Node head) {
    if (head == null) return null;
    return head.next;
}
الشرح: ببساطة أرجِع head.next. تصبح عقدة الرأس القديمة مؤهلة لجمع المهملات (Garbage Collection). الزمن: O(1)، المساحة: O(1).
س7متوسط
حذف العقدة الأخيرة
اكتب دالة Node deleteLast(Node head) تحذف العقدة الأخيرة من القائمة.
قبل:
head 10next → 20next → 30حذف → null
بعد:
head 10next → 20next → null

الحل:

كود الحل
public Node deleteLast(Node head) {
    if (head == null || head.next == null) return null;
    Node current = head;
    while (current.next.next != null) {
        current = current.next;
    }
    current.next = null;
    return head;
}
الشرح: اجتز القائمة حتى current.next.next == null (العقدة قبل الأخيرة)، ثم اجعل current.next = null. الزمن: O(n)، المساحة: O(1).
س8متوسط
حذف عقدة حسب قيمتها
اكتب دالة Node deleteByValue(Node head, int value) تحذف أول ظهور للقيمة المعطاة.
قبل (حذف 20):
head 10next → 20حذف → 30next → null
بعد:
head 10next → 30next → null

الحل:

كود الحل
public Node deleteByValue(Node head, int value) {
    if (head == null) return null;
    if (head.data == value) return head.next;
    Node current = head;
    while (current.next != null) {
        if (current.next.data == value) {
            current.next = current.next.next;
            return head;
        }
        current = current.next;
    }
    return head;
}
الشرح: تحقق أولاً مما إذا كان head يحمل القيمة. ثم اجتز القائمة مع فحص current.next.data. عند العثور عليها، تخطَّها بجعل current.next = current.next.next. الزمن: O(n)، المساحة: O(1).
س9متوسط
الإدراج في موضع محدد
اكتب دالة Node insertAtPosition(Node head, int data, int position) تُدرج عقدة في الموضع المعطى (الفهرسة تبدأ من 0).
قبل:
head 10next → 20next → 30next → null
بعد إدراج 25 في الموضع 2:
head 10next → 20next → 25جديد → 30next → null

الحل:

كود الحل
public Node insertAtPosition(Node head, int data, int pos) {
    Node newNode = new Node(data);
    if (pos == 0) {
        newNode.next = head;
        return newNode;
    }
    Node current = head;
    for (int i = 0; i < pos - 1 && current != null; i++) {
        current = current.next;
    }
    if (current == null) return head;
    newNode.next = current.next;
    current.next = newNode;
    return head;
}
الشرح: انتقل إلى الموضع position-1، ثم أدرج العقدة بتعديل المراجع. عالج الحالة الخاصة للإدراج في الموضع 0 (رأس جديد). الزمن: O(n)، المساحة: O(1).
س10متوسط
عكس قائمة مرتبطة
اكتب دالة Node reverse(Node head) تعكس القائمة في مكانها (In-place).
قبل:
head 1next → 2next → 3next → 4next → null
بعد:
head 4next → 3next → 2next → 1next → null

الحل:

كود الحل
public Node reverse(Node head) {
    Node prev = null;
    Node current = head;
    while (current != null) {
        Node nextTemp = current.next;
        current.next = prev;
        prev = current;
        current = nextTemp;
    }
    return prev;
}
الشرح: استخدم ثلاثة مراجع: prev وcurrent وnextTemp. في كل خطوة، اعكس اتجاه الرابط. عند الانتهاء، يكون prev هو رأس القائمة الجديد. الزمن: O(n)، المساحة: O(1).
س11متوسط
إيجاد العقدة الوسطى
اكتب دالة Node findMiddle(Node head) تُرجع العقدة الوسطى باستخدام تقنية المرجعين البطيء والسريع (Slow/Fast Pointers).
head 1next → 2next → 3الوسط → 4next → 5next → null

الحل:

كود الحل
public Node findMiddle(Node head) {
    Node slow = head;
    Node fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
الشرح: يتحرك slow خطوة واحدة، ويتحرك fast خطوتين. عندما يصل fast إلى النهاية، يكون slow في المنتصف. الزمن: O(n)، المساحة: O(1).
س12متوسط
اكتشاف الدورة (Cycle) (خوارزمية فلويد - Floyd's Algorithm)
اكتب دالة boolean hasCycle(Node head) تكتشف ما إذا كانت القائمة المرتبطة تحتوي على دورة.
head 1next → 2next → 3next → 4next ↶ عودة إلى 3

الحل:

كود الحل
public boolean hasCycle(Node head) {
    Node slow = head;
    Node fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
الشرح: اكتشاف الدورة بطريقة فلويد: يتحرك المرجع البطيء خطوة واحدة، ويتحرك السريع خطوتين. إذا التقيا فهناك دورة. وإذا وصل السريع إلى null فلا توجد دورة. الزمن: O(n)، المساحة: O(1).
س13متوسط
إيجاد العقدة رقم n من النهاية
اكتب دالة Node nthFromEnd(Node head, int n) تُرجع العقدة رقم n من النهاية.
إيجاد العقدة الثانية من النهاية:
head 10next → 20next → 30next → 40الناتج → 50next → null

الحل:

كود الحل
public Node nthFromEnd(Node head, int n) {
    Node fast = head;
    Node slow = head;
    // Move fast n steps ahead
    for (int i = 0; i < n; i++) {
        if (fast == null) return null;
        fast = fast.next;
    }
    // Move both until fast reaches end
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow;
}
الشرح: حرّك المرجع السريع n خطوات إلى الأمام أولاً. ثم حرّك المرجعين خطوة واحدة في كل مرة. عندما يصل السريع إلى النهاية، يكون البطيء عند العقدة رقم n من النهاية. الزمن: O(n)، المساحة: O(1).
س14متوسط
إزالة التكرارات من قائمة مرتبة
اكتب دالة Node removeDuplicates(Node head) تزيل القيم المكررة من قائمة مرتبطة مرتبة.
قبل:
head 1next → 1next → 2next → 3next → 3next → null
بعد:
head 1next → 2next → 3next → null

الحل:

كود الحل
public Node removeDuplicates(Node head) {
    Node current = head;
    while (current != null && current.next != null) {
        if (current.data == current.next.data) {
            current.next = current.next.next;
        } else {
            current = current.next;
        }
    }
    return head;
}
الشرح: بما أن القائمة مرتبة، فإن القيم المكررة تكون متجاورة. إذا كان لـ current وnext القيمة نفسها، فتخطَّ العقدة التالية. وإلا فتقدّم. الزمن: O(n)، المساحة: O(1).
س15متوسط
دمج قائمتين مرتبتين
اكتب دالة Node mergeSorted(Node l1, Node l2) تدمج قائمتين مرتبطتين مرتبتين في قائمة واحدة مرتبة.
L1 1next → 3next → 5next → null
L2 2next → 4next → 6next → null
المدمجة 1next → 2next → 3next → 4next → 5next → 6next → null

الحل:

كود الحل
public Node mergeSorted(Node l1, Node l2) {
    Node dummy = new Node(0);
    Node tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.data <= l2.data) {
            tail.next = l1;
            l1 = l1.next;
        } else {
            tail.next = l2;
            l2 = l2.next;
        }
        tail = tail.next;
    }
    tail.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
الشرح: استخدم عقدة وهمية (Dummy Node) لتبسيط الحالات الحدية. قارن رأسي القائمتين، وأرفق الأصغر منهما، ثم تقدّم. في النهاية أرفق العقد المتبقية. الزمن: O(n+m)، المساحة: O(1).
س16متوسط
التحقق مما إذا كانت القائمة المرتبطة متناظرة (Palindrome)
اكتب دالة boolean isPalindrome(Node head) تتحقق مما إذا كانت القائمة تُقرأ بالشكل نفسه من الأمام ومن الخلف.
قائمة متناظرة:
head 1next → 2next → 3next → 2next → 1next → null

الحل:

كود الحل
public boolean isPalindrome(Node head) {
    // Step 1: Find the middle
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // Step 2: Reverse second half
    Node prev = null;
    while (slow != null) {
        Node next = slow.next;
        slow.next = prev;
        prev = slow;
        slow = next;
    }
    // Step 3: Compare both halves
    Node left = head, right = prev;
    while (right != null) {
        if (left.data != right.data) return false;
        left = left.next;
        right = right.next;
    }
    return true;
}
الشرح: أوجد المنتصف، واعكس النصف الثاني، ثم قارن النصفين عنصراً بعنصر. الزمن: O(n)، المساحة: O(1).
س17صعب
تبديل العقد في أزواج
اكتب دالة Node swapPairs(Node head) تبدّل كل عقدتين متجاورتين.
قبل:
head 1next → 2next → 3next → 4next → null
بعد:
head 2next → 1next → 4next → 3next → null

الحل:

كود الحل
public Node swapPairs(Node head) {
    Node dummy = new Node(0);
    dummy.next = head;
    Node prev = dummy;
    while (prev.next != null && prev.next.next != null) {
        Node first = prev.next;
        Node second = prev.next.next;
        first.next = second.next;
        second.next = first;
        prev.next = second;
        prev = first;
    }
    return dummy.next;
}
الشرح: استخدم عقدة وهمية. لكل زوج، أعد ترتيب المراجع: prev -> second -> first -> rest. ثم انقل prev إلى first (التي أصبحت الآن الثانية في الزوج). الزمن: O(n)، المساحة: O(1).
س19صعب
تحويل قائمة مرتبطة أحادية إلى قائمة مرتبطة مزدوجة
بافتراض أن لديك قائمة مرتبطة أحادية لها المرجع head، اكتب دالة تحوّلها إلى قائمة مرتبطة مزدوجة (Doubly Linked List) لها المرجع dHead. يجب أن تحتوي كل عقدة في القائمة الجديدة على المرجعين next وprev معاً.
بافتراض أن لديك هذه القائمة الأحادية (SLL) ذات المرجع head:
head Anext → Bnext → Cnext → null
حوّلها إلى هذه القائمة المزدوجة (DLL) ذات المرجع dHead:

الحل:

كود الحل
public DNode convertToDoubly(Node head) {
    if (head == null) return null;
    DNode dHead = new DNode(head.data);
    DNode dCurrent = dHead;
    Node current = head.next;
    while (current != null) {
        DNode newNode = new DNode(current.data);
        dCurrent.next = newNode;
        newNode.prev = dCurrent;
        dCurrent = newNode;
        current = current.next;
    }
    return dHead;
}
الشرح: أنشئ عقدة مزدوجة جديدة لكل عقدة أحادية. اضبط المرجعين next وprev أثناء الاجتياز. الزمن: O(n)، المساحة: O(n).
