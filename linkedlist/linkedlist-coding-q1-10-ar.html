الأسئلة البرمجية 1-10

تدرّب على العمليات الأساسية في القائمة المرتبطة (Linked List). يتضمن كل سؤال رسمًا توضيحيًا وحلًا مخفيًا مع شيفرة بلغة Java وشرح لها. انقر على «عرض الحل» لإظهار الإجابة.

س1سهل
اجتياز (Traversal) قائمة مرتبطة أحادية (Singly Linked List) وطباعتها
اكتب دالة void printList(Node head) تطبع جميع عناصر القائمة المرتبطة الأحادية مفصولةً بـ -> ، وتنتهي بـ null.
head 10next → 20next → 30next → null
المخرجات المتوقعة: 10 -> 20 -> 30 -> null

الحل:

الدالة printList()
public void printList(Node head) {
    Node current = head;
    while (current != null) {
        System.out.print(current.data + " -> ");
        current = current.next;
    }
    System.out.println("null");
}
الشرح: نستخدم مرجعًا (Pointer) باسم current يبدأ من head. في كل تكرار لحلقة while نطبع بيانات العقدة (Node) الحالية متبوعةً بـ " -> "، ثم نحرّك المرجع بالتعليمة current = current.next. وعندما يصبح current مساويًا لـ null نخرج من الحلقة ونطبع "null" للدلالة على نهاية القائمة.
التعقيد الزمني (Time Complexity): O(n) — نزور كل عقدة مرة واحدة بالضبط.
التعقيد المكاني (Space Complexity): O(1) — نستخدم متغير مرجع واحدًا فقط.
س2سهل
عدّ العقد في قائمة مرتبطة
اكتب دالة int countNodes(Node head) تُرجع العدد الكلي للعقد في القائمة.
head 5next → 12next → 7next → 3next → null
المخرجات المتوقعة: 4

الحل:

الدالة countNodes()
public int countNodes(Node head) {
    int count = 0;
    Node current = head;
    while (current != null) {
        count++;
        current = current.next;
    }
    return count;
}
الشرح: نهيّئ متغيرًا count بالقيمة 0. نجتاز القائمة باستخدام المرجع current ونزيد count عند كل عقدة. وعندما يصل current إلى null يكون count محتويًا على العدد الكلي للعقد.
التعقيد الزمني: O(n) — نجتاز القائمة كاملةً مرة واحدة.
التعقيد المكاني: O(1) — نستخدم عدّادًا ومرجعًا فقط.
س3سهل
الإدراج في البداية
اكتب دالة Node insertAtHead(Node head, int data) تُدرج عقدة جديدة في بداية القائمة وتُرجع رأس القائمة (Head) الجديد.
قبل:
head 20next → 30next → null
بعد إدراج 10:
head 10next → 20next → 30next → null

الحل:

الدالة insertAtHead()
public Node insertAtHead(Node head, int data) {
    Node newNode = new Node(data);
    newNode.next = head;
    return newNode;
}
الشرح: ننشئ عقدة جديدة بالبيانات المعطاة، ونجعل المرجع next للعقدة الجديدة يشير إلى head الحالي، ثم نُرجع العقدة الجديدة بوصفها رأس القائمة الجديد. ويعمل ذلك حتى لو كان head مساويًا لـ null (قائمة فارغة).
التعقيد الزمني: O(1) — لا حاجة إلى الاجتياز.
التعقيد المكاني: O(1) — تُنشأ عقدة جديدة واحدة فقط.
س4سهل
الإدراج في النهاية
اكتب دالة Node insertAtEnd(Node head, int data) تُدرج عقدة جديدة في نهاية القائمة وتُرجع رأس القائمة.
قبل:
head 10next → 20next → null
بعد إدراج 30:
head 10next → 20next → 30next → null

الحل:

الدالة insertAtEnd()
public Node insertAtEnd(Node head, int data) {
    Node newNode = new Node(data);
    if (head == null) return newNode;
    Node current = head;
    while (current.next != null) {
        current = current.next;
    }
    current.next = newNode;
    return head;
}
الشرح: ننشئ عقدة جديدة. إذا كانت القائمة فارغة (head == null) نُرجع العقدة الجديدة بوصفها رأس القائمة. وإلا نجتاز القائمة حتى آخر عقدة (حيث current.next == null) ونجعل مرجعها next يشير إلى العقدة الجديدة.
التعقيد الزمني: O(n) — يجب أن نجتاز القائمة حتى نهايتها.
التعقيد المكاني: O(1) — نستخدم عقدة جديدة واحدة ومرجعًا واحدًا فقط.
س5سهل
البحث عن قيمة
اكتب دالة boolean search(Node head, int target) تُرجع true إذا كانت القيمة المطلوبة موجودة في القائمة، وfalse خلاف ذلك.
head (البحث عن 15) 4next → 8next → 15next → 23next → null
البحث عن 15 ← يُرجع true

الحل:

الدالة search()
public boolean search(Node head, int target) {
    Node current = head;
    while (current != null) {
        if (current.data == target) {
            return true;
        }
        current = current.next;
    }
    return false;
}
الشرح: ننفّذ بحثًا خطيًا (Linear Search) باجتياز كل عقدة ومقارنة current.data بـ target. إذا وُجد تطابق نُرجع true فورًا. وإذا وصلنا إلى نهاية القائمة دون العثور على القيمة المطلوبة نُرجع false.
التعقيد الزمني: O(n) — في أسوأ حالة (Worst Case) نفحص كل العقد.
التعقيد المكاني: O(1) — نستخدم متغير مرجع واحدًا فقط.
س6سهل
حذف العقدة الأولى
اكتب دالة Node deleteFirst(Node head) تحذف العقدة الأولى من القائمة وتُرجع رأس القائمة الجديد.
قبل:
head 10حذف → 20next → 30next → null
بعد:
head 20next → 30next → null

الحل:

الدالة deleteFirst()
public Node deleteFirst(Node head) {
    if (head == null) return null;
    return head.next;
}
الشرح: نُرجع ببساطة head.next الذي يصبح رأس القائمة الجديد. لم تعد عقدة الرأس القديمة مُشارًا إليها بأي مرجع، فتصبح مؤهلة لجمع المهملات (Garbage Collection) في Java. ونعالج الحالة الحدّية للقائمة الفارغة بالتحقق مما إذا كان head مساويًا لـ null.
التعقيد الزمني: O(1) — لا حاجة إلى الاجتياز.
التعقيد المكاني: O(1) — لا نستخدم مساحة إضافية.
س7متوسط
حذف العقدة الأخيرة
اكتب دالة Node deleteLast(Node head) تحذف العقدة الأخيرة من القائمة وتُرجع رأس القائمة.
قبل:
head 10next → 20next → 30حذف → null
بعد:
head 10next → 20next → null

الحل:

الدالة deleteLast()
public Node deleteLast(Node head) {
    if (head == null || head.next == null) {
        return null;
    }
    Node current = head;
    while (current.next.next != null) {
        current = current.next;
    }
    current.next = null;
    return head;
}
الشرح: نحتاج إلى الوصول إلى العقدة قبل الأخيرة لنجعل next الخاص بها مساويًا لـ null. نجتاز القائمة باستخدام الشرط current.next.next != null لنتوقف قبل العقدة الأخيرة بعقدة واحدة. الحالات الحدّية: إذا كانت القائمة فارغة أو تحتوي على عقدة واحدة فقط نُرجع null.
التعقيد الزمني: O(n) — نجتاز القائمة كلها تقريبًا.
التعقيد المكاني: O(1) — نستخدم متغير مرجع واحدًا فقط.
س8متوسط
حذف عقدة حسب قيمتها
اكتب دالة Node deleteByValue(Node head, int value) تحذف أول ظهور للقيمة المعطاة من القائمة.
حذف 20:
head 10next → 20حذف → 30next → null
بعد:
head 10next → 30next → null

الحل:

الدالة deleteByValue()
public Node deleteByValue(Node head, int value) {
    if (head == null) return null;
    // If the head node holds the value to delete
    if (head.data == value) return head.next;
    Node current = head;
    while (current.next != null) {
        if (current.next.data == value) {
            current.next = current.next.next;
            return head;
        }
        current = current.next;
    }
    return head; // value not found
}
الشرح: أولًا نتحقق مما إذا كان الرأس نفسه يحتوي على القيمة؛ فإن كان كذلك نُرجع head.next. وإلا نجتاز القائمة ونفحص current.next.data. وعند العثور على القيمة نتخطى العقدة المطلوبة بالتعليمة current.next = current.next.next. وإذا لم تكن القيمة موجودة في القائمة يُرجَع الرأس الأصلي دون تغيير.
التعقيد الزمني: O(n) — في أسوأ حالة تكون القيمة في النهاية أو غير موجودة.
التعقيد المكاني: O(1) — نستخدم متغير مرجع واحدًا فقط.
س9متوسط
الإدراج في موضع محدد
اكتب دالة Node insertAtPosition(Node head, int data, int position) تُدرج عقدة جديدة في الموضع المعطى (يبدأ الفهرس (Index) من 0).
قبل:
head 10next → 20next → 30next → null
بعد إدراج 25 في الموضع 2:
head 10next → 20next → 25جديد → 30next → null

الحل:

الدالة insertAtPosition()
public Node insertAtPosition(Node head, int data, int position) {
    Node newNode = new Node(data);
    // Insert at the beginning
    if (position == 0) {
        newNode.next = head;
        return newNode;
    }
    Node current = head;
    for (int i = 0; i < position - 1 && current != null; i++) {
        current = current.next;
    }
    if (current == null) return head; // position out of bounds
    newNode.next = current.next;
    current.next = newNode;
    return head;
}
الشرح: إذا كان position يساوي 0 نُدرج في الرأس. وإلا ننتقل إلى العقدة ذات الفهرس position - 1، ثم نُدرج العقدة الجديدة بجعل newNode.next يشير إلى current.next، وتحديث current.next ليشير إلى newNode. ونعالج أيضًا الحالة التي يتجاوز فيها الموضع طول القائمة.
التعقيد الزمني: O(n) — قد نجتاز ما يصل إلى n عقدة للوصول إلى الموضع.
التعقيد المكاني: O(1) — نستخدم عقدة جديدة واحدة ومرجعًا واحدًا فقط.
س10متوسط
عكس قائمة مرتبطة
اكتب دالة Node reverse(Node head) تعكس القائمة المرتبطة في مكانها (In-place) وتُرجع رأس القائمة الجديد.
قبل:
head 1next → 2next → 3next → 4next → null
بعد:
head 4next → 3next → 2next → 1next → null

الحل:

الدالة reverse()
public Node reverse(Node head) {
    Node prev = null;
    Node current = head;
    while (current != null) {
        Node nextTemp = current.next; // save next node
        current.next = prev;            // reverse the link
        prev = current;                 // move prev forward
        current = nextTemp;             // move current forward
    }
    return prev; // prev is the new head
}
الشرح: نستخدم ثلاثة مراجع: prev (يبدأ من null)، وcurrent (يبدأ من head)، وnextTemp (لحفظ العقدة التالية قبل أن نستبدل الرابط). في كل تكرار: (1) نحفظ current.next في nextTemp، (2) نعكس الرابط بجعل current.next يشير إلى prev، (3) نحرّك prev وcurrent خطوة واحدة إلى الأمام. وعندما يصبح current مساويًا لـ null يشير prev إلى رأس القائمة المعكوسة الجديد.
التعقيد الزمني: O(n) — نزور كل عقدة مرة واحدة بالضبط.
التعقيد المكاني: O(1) — نستخدم ثلاثة متغيرات مرجعية فقط (عكس في المكان).
