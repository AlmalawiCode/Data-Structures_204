أنواع القوائم المرتبطة (Types of Linked Lists)

هياكل البيانات 1

القوائم المرتبطة الدائرية، والمزدوجة، والمزدوجة الدائرية (Circular, Doubly, and Circular Doubly Linked Lists)

التنقل السريع

المقدمة

كما ناقشنا سابقًا، في القائمة المرتبطة الأحادية (Singly Linked List) تشير كل عقدة (Node) إلى العقدة التالية، وتشير العقدة الأخيرة إلى null. سنستكشف الآن ثلاثة أنواع مهمة من القوائم المرتبطة:
  1. القائمة المرتبطة الأحادية الدائرية (Circular Singly Linked List)
  2. القائمة المرتبطة المزدوجة (Doubly Linked List)
  3. القائمة المرتبطة المزدوجة الدائرية (Circular Doubly Linked List)
كل نوع يحل مشكلات محددة وله استخداماته الخاصة. لنبدأ بالقائمة المرتبطة الدائرية!
تذكير: في القائمة المرتبطة الأحادية، تحتوي كل عقدة على:
  • البيانات (Data) - القيمة المخزنة في العقدة
  • التالي (Next) - مرجع (Reference) يشير إلى العقدة التالية (أو null إذا كانت العقدة الأخيرة)

1. القائمة المرتبطة الأحادية الدائرية (Circular Singly Linked List)

↺

المحاكي التفاعلي للقائمة المرتبطة الدائرية (Circular Linked List)

شاهد رابط الالتفاف يبقى مغلقًا في كل عملية، جملة جافا واحدة في كل مرة — بما في ذلك العقدة الوحيدة التي تشير إلى نفسها، وشرط الحلقة الذي يقارن بـ tail بدلًا من null.

افتح المحاكي ←

ما هي القائمة المرتبطة الدائرية؟

القائمة المرتبطة الأحادية الدائرية (Circular Singly Linked List) هي شكل مُعدَّل من القائمة المرتبطة الأحادية، حيث يشير مؤشر next في العقدة الأخيرة إلى العقدة الأولى بدلًا من null. وهذا يُنشئ سلسلة دائرية ليس لها نهاية!
تخيلها كحلقة من الأصدقاء يمسكون بأيدي بعضهم. الشخص الأخير لا يترك يده - بل يمسك بيد الشخص الأول، فتكتمل الدائرة!

التمثيل المرئي

ملاحظة أساسية: في القائمة المرتبطة الدائرية لا يوجد مؤشر null! فالعقدة الأخيرة تشير دائمًا إلى العقدة الأولى.

تطبيقات من الواقع

التطبيق 1: جدولة عمليات المعالج - جدولة رون روبن (Round-Robin)

تخيل أن المعالج (CPU) يحتاج إلى تنفيذ 3 عمليات: P1 و P2 و P3. باستخدام القائمة المرتبطة الدائرية:

  • يعطي المعالج العملية P1 شريحة زمنية (مثلًا 5 ميلي ثانية)
  • ثم ينتقل إلى P2 (5 ميلي ثانية)
  • ثم ينتقل إلى P3 (5 ميلي ثانية)
  • ثم يعود تلقائيًا إلى P1 ويستمر في الدورة!

يسمى هذا جدولة رون روبن (Round Robin Scheduling) - والقائمة المرتبطة الدائرية مثالية لذلك!

التطبيق 2: ألعاب الطاولة متعددة اللاعبين

فكر في لعبة مثل مونوبولي (Monopoly) مع 4 لاعبين:

  • اللاعب 1 يأخذ دوره
  • ثم اللاعب 2، فاللاعب 3، فاللاعب 4
  • ثم يعود الدور إلى اللاعب 1 تلقائيًا!

القائمة المرتبطة الدائرية تمثل نمط تبادل الأدوار هذا بشكل طبيعي.

التنفيذ باستخدام head و tail

لتسهيل التنفيذ، سنستخدم المؤشرين head و tail معًا. مؤشر tail يجعل الإضافة في نهاية القائمة أكثر كفاءة بكثير - O(1) بدلًا من O(n)!

فئة العقدة للقائمة المرتبطة الدائرية

Node.java - نفس القائمة المرتبطة الأحادية (Singly Linked List)
public class Node {
    int data;
    Node next;

    public Node(int data) {
        this.data = data;
        this.next = null;
    }
}

التنفيذ الكامل (Complete Implementation)

CircularLinkedList.java
public class CircularLinkedList {
    Node head;
    Node tail;

    // Add node at the end
    public void addLast(int data) {
        Node newNode = new Node(data);

        if (head == null) {
            // First node - points to itself
            head = newNode;
            tail = newNode;
            tail.next = head;
        } else {
            // Add after tail, update circular reference
            newNode.next = head;     // New node points to head
            tail.next = newNode;     // Old tail points to new node
            tail = newNode;          // Update tail
        }
    }

    // Add node at the beginning
    public void addFirst(int data) {
        Node newNode = new Node(data);

        if (head == null) {
            head = newNode;
            tail = newNode;
            tail.next = head;
        } else {
            newNode.next = head;     // New node points to old head
            head = newNode;          // Update head
            tail.next = head;        // Tail must point to new head!
        }
    }
}

اجتياز القائمة المرتبطة الدائرية (Traversing a Circular Linked List)

خطر: حلقة لا نهائية!

بما أنه لا يوجد null نتوقف عنده، فإن استخدام حلقة while العادية مثل while (current != null) سيستمر في التنفيذ إلى الأبد!

نحتاج إلى شرط خاص للتوقف. يمكننا إما:
  1. استخدام حلقة do-while والتوقف عند العودة إلى head
  2. استخدام حلقة while مع شرط مصاغ بعناية

الطريقة الأولى: استخدام حلقة do-while

الاجتياز باستخدام حلقة do-while (Traversal with do-while)
public void printList() {
    if (head == null) {
        System.out.println("List is empty");
        return;
    }

    Node current = head;

    // do-while ensures we visit at least once, then stop when back at head
    do {
        System.out.print(current.data + " -> ");
        current = current.next;
    } while (current != head);

    System.out.println("(back to head)");
}

// Output: 10 -> 20 -> 30 -> (back to head)
لماذا حلقة do-while؟

تُنفَّذ حلقة do-while مرة واحدة على الأقل قبل فحص الشرط. وهذا مثالي للأسباب التالية:

  • نبدأ من head ونريد معالجته
  • نواصل التقدم حتى نعود إلى head
  • لو استخدمنا while (current != head)، لما دخلنا الحلقة أبداً!

الطريقة الثانية: استخدام حلقة while مع متغيّر تحكم

الاجتياز باستخدام حلقة while - طريقة بديلة (Traversal with while Loop)
public void printListWhile() {
    if (head == null) {
        System.out.println("List is empty");
        return;
    }

    Node current = head;
    boolean firstIteration = true;

    while (firstIteration || current != head) {
        System.out.print(current.data + " -> ");
        current = current.next;
        firstIteration = false;
    }

    System.out.println("(back to head)");
}
أفضل ممارسة: أسلوب حلقة do-while أكثر وضوحاً وأكثر شيوعاً في اجتياز القوائم الدائرية.

2. القائمة المرتبطة المزدوجة (Doubly Linked List)

⇄

المحاكي التفاعلي للقائمة المرتبطة المزدوجة (Doubly Linked List)

شاهد كل عملية في هذا القسم تُنفَّذ جملة جافا واحدة في كل مرة — الإدراج بأربعة روابط، و addLast/deleteLast بتكلفة O(1) عبر tail، والحذف الذي يقف على العقدة نفسها — مع أسهم prev/next متحركة وأسئلة صفية.

افتح المحاكي ←

مشكلة القوائم المرتبطة الأحادية

يا دكتور، ماذا لو كنت في منتصف قائمة مرتبطة أحادية واحتجت إلى العودة إلى العقدة (Node) السابقة؟
سؤال ممتاز! في القائمة المرتبطة الأحادية لا يمكنك الرجوع للخلف. فبمجرد أن تتقدم للأمام، تكون قد فقدت المرجع (Reference) إلى العقدة السابقة. وللعودة إلى الخلف، سيتعين عليك البدء من head من جديد، أي بتكلفة O(n) في كل مرة!
القائمة المرتبطة المزدوجة تحل هذه المشكلة بوجود مؤشرين في كل عقدة:
  • next - يشير إلى العقدة التالية (الاتجاه للأمام (Forward))
  • prev - يشير إلى العقدة السابقة (الاتجاه للخلف (Backward))
وهذا يتيح الاجتياز (Traversal) في الاتجاهين!

التنفيذ الكامل

ملف القائمة المرتبطة المزدوجة (DoublyLinkedList.java)
public class DoublyLinkedList {

    // Inner Node class
    class Node {
        int data;
        Node next;
        Node prev;

        public Node(int data) {
            this.data = data;
            this.next = null;
            this.prev = null;
        }
    }

    Node head;
    Node tail;

    // Add node at the end
    public void addLast(int data) {
        Node newNode = new Node(data);

        if (head == null) {
            // First node - both head and tail point to it
            head = newNode;
            tail = newNode;
        } else {
            // Link new node with current tail
            newNode.prev = tail;     // New node's prev points to old tail
            tail.next = newNode;     // Old tail's next points to new node
            tail = newNode;          // Update tail to new node
        }
    }

    // Add node at the beginning
    public void addFirst(int data) {
        Node newNode = new Node(data);

        if (head == null) {
            head = newNode;
            tail = newNode;
        } else {
            newNode.next = head;     // New node points to old head
            head.prev = newNode;     // Old head's prev points to new node
            head = newNode;          // Update head to new node
        }
    }

    // Print list forward
    public void printForward() {
        Node current = head;
        System.out.print("Forward: ");
        while (current != null) {
            System.out.print(current.data + " <-> ");
            current = current.next;
        }
        System.out.println("null");
    }

    // Print list backward (starting from tail!)
    public void printBackward() {
        Node current = tail;
        System.out.print("Backward: ");
        while (current != null) {
            System.out.print(current.data + " <-> ");
            current = current.prev;
        }
        System.out.println("null");
    }
}
الميزة الأساسية: في القائمة المرتبطة المزدوجة (Doubly Linked List)، يمكننا الاجتياز في كلا الاتجاهين! وهذا يجعل عمليات مثل حذف عقدة معيّنة أسهل بكثير - فلا نحتاج إلى تتبّع العقدة السابقة بشكل منفصل.

3. القائمة المرتبطة المزدوجة الدائرية (Circular Doubly Linked List)

تجمع القائمة المرتبطة المزدوجة الدائرية بين خصائص النوعين معًا:
  • دائرية (Circular) - ترتبط العقدة الأخيرة بالعقدة الأولى مرة أخرى
  • مزدوجة (Doubly) - تمتلك كل عقدة (Node) مؤشرَي next وprev معًا
وينتج عن ذلك دائرة ثنائية الاتجاه يمكنك فيها التنقّل إلى ما لا نهاية في كلا الاتجاهين!
تخيّلها كلعبة دوّارة (merry-go-round) يمكنك السير فيها في أي اتجاه، وستعود في النهاية إلى النقطة التي بدأت منها!

التمثيل المرئي

نقاط أساسية:
  • tail.next = head (مؤشر next للعقدة الأخيرة يشير إلى العقدة الأولى)
  • head.prev = tail (مؤشر prev للعقدة الأولى يشير إلى العقدة الأخيرة)
  • لا توجد مؤشرات null في أي موضع!
  • يمكن التنقّل إلى ما لا نهاية في كلا الاتجاهين

تطبيق من الحياة الواقعية

تطبيق: مشغّل الوسائط مع وضع التكرار

عند تفعيل خيار "تكرار الكل" (Repeat All) في قائمة التشغيل:

  • بعد المقطع الأخير، يعود التشغيل إلى المقطع الأول (دائرية)
  • يمكن للمستخدم الضغط على "التالي" أو "السابق" (مزدوجة)
  • لا يتوقف أبدًا - يستمر في الدوران عبر قائمة التشغيل!

التنفيذ البرمجي

ملف (CircularDoublyLinkedList.java)
public class CircularDoublyLinkedList {

    // Inner Node class
    class Node {
        int data;
        Node next;
        Node prev;

        public Node(int data) {
            this.data = data;
        }
    }

    Node head;
    Node tail;

    // Add node at the end
    public void addLast(int data) {
        Node newNode = new Node(data);

        if (head == null) {
            // First node - points to itself in both directions
            head = newNode;
            tail = newNode;
            newNode.next = newNode;  // Points to itself
            newNode.prev = newNode;  // Points to itself
        } else {
            // Insert between tail and head
            newNode.prev = tail;     // New node's prev = old tail
            newNode.next = head;     // New node's next = head (circular!)
            tail.next = newNode;     // Old tail's next = new node
            head.prev = newNode;     // Head's prev = new node (circular!)
            tail = newNode;          // Update tail
        }
    }

    // Add node at the beginning
    public void addFirst(int data) {
        Node newNode = new Node(data);

        if (head == null) {
            head = newNode;
            tail = newNode;
            newNode.next = newNode;
            newNode.prev = newNode;
        } else {
            // Insert between tail and head
            newNode.next = head;     // New node's next = old head
            newNode.prev = tail;     // New node's prev = tail (circular!)
            head.prev = newNode;     // Old head's prev = new node
            tail.next = newNode;     // Tail's next = new node (circular!)
            head = newNode;          // Update head
        }
    }

    // Print list (be careful of infinite loop!)
    public void printList() {
        if (head == null) {
            System.out.println("List is empty");
            return;
        }

        Node current = head;
        System.out.print("List: ");

        do {
            System.out.print(current.data + " <-> ");
            current = current.next;
        } while (current != head);

        System.out.println("(back to head)");
    }
}
تذكّر: استخدم دائمًا حلقة do-while مع الشرط current != head لتجنّب الحلقات اللانهائية عند التنقّل في القوائم الدائرية!

مقارنة بين جميع الأنواع

الخاصية القائمة المرتبطة الأحادية (Singly Linked List) الأحادية الدائرية (Circular Singly) القائمة المرتبطة المزدوجة (Doubly Linked List) المزدوجة الدائرية (Circular Doubly)
اتجاه التنقّل للأمام فقط للأمام فقط (دائرية) للأمام والخلف للأمام والخلف (دائرية)
العقدة الأخيرة تشير إلى null head (العقدة الأولى) null head (العقدة الأولى)
مؤشر prev للعقدة الأولى لا ينطبق لا ينطبق null tail (العقدة الأخيرة)
استهلاك الذاكرة (Memory) لكل عقدة البيانات + مؤشر واحد البيانات + مؤشر واحد البيانات + مؤشران البيانات + مؤشران
الانتقال إلى العقدة السابقة O(n) - البدء من head O(n) - البدء من head O(1) - استخدام prev O(1) - استخدام prev
حالة الاستخدام القوائم البسيطة الجدولة الدورية (Round-robin)، والتكرار الدوري سجلّ المتصفح مشغّلات الوسائط مع خاصية التكرار

الملخّص

متى تستخدم كل نوع:
  • القائمة المرتبطة الأحادية: عندما تحتاج إلى التنقّل للأمام فقط وتريد أقل استهلاك للذاكرة
  • الأحادية الدائرية: عندما تحتاج إلى دوران مستمر (جدولة المعالج، والألعاب القائمة على الأدوار)
  • القائمة المرتبطة المزدوجة: عندما تحتاج إلى تنقّل ثنائي الاتجاه (التراجع/الإعادة، وسجلّ المتصفح)
  • المزدوجة الدائرية: عندما تحتاج إلى وصول دائري وثنائي الاتجاه معًا (مشغّل موسيقى مع خاصية التكرار)
