2. Which statement describes the stack as a logical data structure?

(a) an array of size n with an index top    (b) a chain of nodes linked by next    (c) a collection where insertion and deletion happen at one end only (LIFO)    (d) a block of consecutive memory addresses

3. Which of the following is a physical structure that can be used to implement a stack?

(a) LIFO    (b) push / pop    (c) an array or a linked list    (d) an ADT

4. A program uses only push, pop, top and isEmpty. The stack is changed from an array to a linked list. The program:

(a) must be rewritten    (b) works unchanged, because the abstract operations stay the same    (c) now behaves as FIFO    (d) can no longer call top()

(b) True or False. [2 marks · 1 each]

  i.  isFull() is required in a linked-list implementation of a stack.    ______

  ii. A stack's LIFO behaviour is the same whether it is implemented with an array or a linked list.    ______

(c) Explain the difference between the logical view and the physical view of a stack. Give one example of each. [4 marks]

Model Answer — Q1

(a) 1: (b)   2: (c)   3: (c)   4: (b)

(b) i. False — a linked stack grows dynamically    ii. True

(c) The logical view describes what a stack is and how it is used: a LIFO collection accessed only at the top through push, pop, top, isEmpty. The physical view describes how it is stored in memory: e.g. an array with a top index (contiguous memory) or a linked list whose head is the top (nodes and references). The physical view can change without changing the logical view — that is the essence of abstraction.

Rubric (c): logical = behaviour / operations / LIFO 2 · physical = memory representation with an example (array or linked list) 2.

Q4 Push and Pop — Linked-List-Based Stack MEDIUM CLO 8SO-2 10 marks

In StackUsingLinkedList<T> the field top refers to the first node of the list (the top of the stack); each Node<T> has data and next.

(a) Fill in the five blanks. [5 marks · 1 each]

public void push(T element) {    Node<T> newNode = new Node<>(element);    newNode.next = ______________;          // (i)    top = ______________;                   // (ii)    size++;}public T pop() {    if ( ______________ ) {                 // (iii)        System.out.println("Stack Underflow!");        return null;    }    T data = ______________;                // (iv)    top = ______________;                   // (v)    size--;    return data;}

(b) In push, a student swaps lines (i) and (ii), writing top = newNode; before newNode.next = top;. What goes wrong? [2 marks]

(c) Why are push and pop done at the head of the list and not at the tail? State the time complexity of each. [3 marks]

Model Answer — Q4
public void push(T element) {    Node<T> newNode = new Node<>(element);    newNode.next = top;          // (i)    top = newNode;                   // (ii)    size++;}public T pop() {    if ( isEmpty()  /  top == null ) {                 // (iii)        System.out.println("Stack Underflow!");        return null;    }    T data = top.data;                // (iv)    top = top.next;                   // (v)    size--;    return data;}

(b) After top = newNode, the statement newNode.next = top makes the new node point to itself. The reference to the old top is lost, so the rest of the stack is lost (and traversal loops forever).

(c) Inserting and removing at the head only changes top, with no traversal: push and pop are both O(1). Popping at the tail would need a walk to the second-last node — O(n) for a singly linked list.

Rubric: (a) 1 per blank · (b) self-loop / old nodes lost 2 · (c) reason 2 + O(1) 1.
