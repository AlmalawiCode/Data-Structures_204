العودية على السلاسل النصية (String Recursion)

هياكل البيانات 1

خوارزميات عودية على السلاسل النصية والبحث الثنائي

1. مقدمة إلى العودية على السلاسل النصية

أهلًا بكم من جديد! رأينا كيف تعمل العودية (Recursion) مع الأعداد، والآن سنطبّق الأفكار نفسها على السلاسل النصية (Strings). السلسلة النصية هي تتابع من الحروف، والعودية على السلاسل تتبع نمطًا جميلًا: نحلّ المسألة للحرف الأول، ثم نعالج بقية السلسلة عوديًا.
إذن بدلًا من تصغير العدد في كل مرة، نجعل السلسلة أقصر؟
بالضبط! كل دالة عودية على السلاسل النصية تحتوي على:
• الحالة الأساسية (Base Case): السلسلة الفارغة "" → نعود فورًا (أو نُرجع 0 / "")
• الحالة العودية (Recursive Case): نعالج s.charAt(0)، ثم نستدعي الدالة بـ s.substring(1)
ما سنغطيه اليوم:
  1. printChars — طباعة كل حرف من اليسار إلى اليمين
  2. printReverse — طباعة الحروف بترتيب معكوس
  3. countChar — عدّ مرات ظهور حرف معيّن
  4. replaceChar — استبدال حرف بحرف آخر
  5. removeChar — حذف جميع مرات ظهور حرف معيّن
  6. البحث الثنائي (Binary Search) — بالطريقتين التكرارية والعودية
الفكرة الجوهرية الفكرة الجوهرية في العودية على السلاسل: s.charAt(0) يعطي الحرف الأول، وs.substring(1) يعطي كل ما بعده. كل استدعاء عودي يعمل على سلسلة أقصر — وهذا ما يضمن وصولنا إلى الحالة الأساسية!

2. الدالة printChars("JAVA")

تحدّينا الأول: طباعة كل حرف في السلسلة، حرفًا حرفًا، باستخدام العودية. لا يُسمح بالحلقات التكرارية! الفكرة بسيطة — اطبع الحرف الأول، ثم اطبع الباقي عوديًا.
إذن لو كانت لديّ "JAVA"، أطبع 'J' ثم أستدعي الدالة على "AVA"؟
ممتاز! و"AVA" تطبع 'A' وتستدعي على "VA"، وهكذا حتى نصل إلى السلسلة الفارغة. تلك هي حالتنا الأساسية!
printChars("") → لا تفعل شيئًا    (الحالة الأساسية)
printChars(s)  → اطبع s.charAt(0)، ثم printChars(s.substring(1))    (الحالة العودية)
Java — طباعة الحروف عوديًا ▼
public class StringRecursion { public static void printChars(String s) { if (s.isEmpty()) return; // Base case: empty string System.out.print(s.charAt(0) + " "); // Print first character printChars(s.substring(1)); // Recurse on the rest } public static void main(String[] args) { printChars("JAVA"); // Output: J A V A } }

لاحظ أن كل الطباعة تحدث في طريق النزول (مرحلة الدفع push) — فمع إضافة كل إطار (Frame)، يطبع حرفه فورًا، قبل إجراء الاستدعاء العودي. أما مرحلة الرجوع (pop) فتكتفي بإغلاق الإطارات — ولا تحدث أي طباعة عندها.

3. الدالة printReverse("JAVA")

والآن الحيلة السحرية — ماذا لو أردنا طباعة الحروف بترتيب معكوس؟ ببساطة نجري الاستدعاء العودي أولًا، ثم نطبع. هذا التغيير الصغير في الترتيب يعكس الناتج تمامًا!
إذن ننزل حتى الحالة الأساسية أولًا، ثم نطبع في طريق العودة إلى الأعلى؟
بالضبط! الاستدعاءات العودية تدفع كل شيء إلى مكدس الاستدعاءات (Call Stack). ولا نبدأ بالرجوع إلا عند الوصول إلى الحالة الأساسية، فيطبع كل إطار حرفه عند خروجه من المكدس. يُسمّى هذا الطباعة في مرحلة "الرجوع" (Unwinding).
printReverse("") → لا تفعل شيئًا    (الحالة الأساسية)
printReverse(s)  → printReverse(s.substring(1))، ثم اطبع s.charAt(0)    (الحالة العودية)

لاحظ الفرق الجوهري: الاستدعاء العودي يأتي قبل الطباعة!
Java — الطباعة المعكوسة عوديًا ▼
public class StringRecursion { public static void printReverse(String s) { if (s.isEmpty()) return; // Base case: empty string printReverse(s.substring(1)); // Recurse FIRST System.out.print(s.charAt(0) + " "); // Then print (on unwind!) } public static void main(String[] args) { printReverse("JAVA"); // Output: A V A J } }

قوة العودية هذه هي قوة العودية! بوضع جملة الطباعة بعد الاستدعاء العودي، تُطبع الحروف بترتيب معكوس. يعمل مكدس الاستدعاءات كمخزن مؤقت — يحتفظ بكل الحروف ثم يطلقها بترتيب «الداخل أخيرًا يخرج أولًا» (LIFO).

4. الدالة countChar("BALL", 'L')

والآن دالة تُرجع قيمة. نريد عدّ مرات ظهور حرف معيّن في سلسلة نصية. في "BALL" مع الحرف 'L'، الجواب هو 2.
هل نفحص كل حرف أثناء التقدّم، ونضيف 1 إذا تطابق؟
بالضبط! إذا تطابق الحرف الأول نساهم بـ 1، ثم نضيف العدد القادم من بقية السلسلة. وإذا لم يتطابق نساهم بـ 0. والحالة الأساسية تُرجع 0 للسلسلة الفارغة.
countChar("", ch) = 0    (الحالة الأساسية)
countChar(s, ch)  = (s.charAt(0)==ch ? 1 : 0) + countChar(s.substring(1), ch)    (الحالة العودية)
Java — عدّ مرات الظهور ▼
public class StringRecursion { public static int countChar(String s, char ch) { if (s.isEmpty()) return 0; // Base case int match = (s.charAt(0) == ch) ? 1 : 0; // 1 if match, else 0 return match + countChar(s.substring(1), ch); // Add to rest } public static void main(String[] args) { int count = countChar("BALL", 'L'); System.out.println("Count = " + count); // Output: Count = 2 } }

5. الدالة replaceChar("HELLO", 'L', 'R')

والآن نبني سلسلة نصية جديدة. نريد استبدال كل 'L' في "HELLO" بالحرف 'R'، فنحصل على "HERRO". نبني النتيجة حرفًا حرفًا أثناء رجوع العودية.
إذن إذا تطابق الحرف نستخدم الحرف الجديد، وإلا نُبقي على الأصلي؟
بالضبط! ونُلحق كل حرف بنتيجة الاستدعاء العودي على بقية السلسلة. والحالة الأساسية تُرجع سلسلة فارغة — وهي نقطة البداية للبناء.
replaceChar("", old, new) = ""    (الحالة الأساسية)
replaceChar(s, old, new)  = (s.charAt(0)==old ? new : s.charAt(0)) + replaceChar(s.substring(1), old, new)
Java — استبدال حرف ▼
public class StringRecursion { public static String replaceChar(String s, char oldCh, char newCh) { if (s.isEmpty()) return ""; // Base case char first = (s.charAt(0) == oldCh) ? newCh : s.charAt(0); return first + replaceChar(s.substring(1), oldCh, newCh); } public static void main(String[] args) { String result = replaceChar("HELLO", 'L', 'R'); System.out.println(result); // Output: HERRO } }

6. الدالة removeChar("HELLO", 'L')

مشابهة للاستبدال، لكننا الآن نحذف كل مرات ظهور الحرف تمامًا. عند حذف 'L' من "HELLO" نحصل على "HEO". وعندما يتطابق الحرف لا نساهم بشيء — أي بسلسلة فارغة.
إذن بدلًا من الاستبدال بحرف جديد، نتخطّاه فحسب؟
نعم! نساهم بـ "" (سلسلة فارغة) عند التطابق، وبـ "" + s.charAt(0) (الحرف نفسه) عند عدم التطابق.
removeChar("", ch) = ""    (الحالة الأساسية)
removeChar(s, ch)  = (s.charAt(0)==ch ? "" : ""+s.charAt(0)) + removeChar(s.substring(1), ch)
Java — حذف حرف ▼
public class StringRecursion { public static String removeChar(String s, char ch) { if (s.isEmpty()) return ""; // Base case String keep = (s.charAt(0) == ch) ? "" : "" + s.charAt(0); return keep + removeChar(s.substring(1), ch); } public static void main(String[] args) { String result = removeChar("HELLO", 'L'); System.out.println(result); // Output: HEO } }

حذف الحرف عندما يُحذف حرف، فإنه يساهم بسلسلة فارغة "". وهذا يعني أن السلسلة تصبح أقصر من الأصلية — إذ لا تُدرج في النتيجة إلا الحروف غير المتطابقة.

7. البحث الثنائي (Binary Search)

البحث الثنائي من أهم الخوارزميات في علوم الحاسب. يبحث في مصفوفة مرتّبة بتقسيم نطاق البحث إلى النصف مرارًا. ويمكننا تنفيذه تكراريًا (بحلقة) وعوديًا.
لماذا المصفوفات المرتّبة فقط؟
لأننا نقارن العنصر الأوسط بالهدف. فإذا كان الهدف أصغر، عرفنا أنه لا بد أن يكون في النصف الأيسر. وإذا كان أكبر فهو في النصف الأيمن. وهذا لا يعمل إلا إذا كانت المصفوفة مرتّبة! كل مقارنة تستبعد نصف العناصر المتبقية — ولهذا فإن البحث الثنائي من رتبة O(log n).
البحث الثنائي في مصفوفة مرتّبة arr[] عن الهدف target:
  - نحتفظ بمؤشرين: low = 0, high = arr.length - 1
  - نحسب mid = (low + high) / 2
  - إذا كان arr[mid] == target: وُجد! نُرجع mid
  - إذا كان arr[mid] < target: نبحث في النصف الأيمن → low = mid + 1
  - إذا كان arr[mid] > target: نبحث في النصف الأيسر → high = mid - 1
  - إذا كان low > high: غير موجود → return -1

7.1 البحث الثنائي التكراري (Iterative)

لنرَ أولًا النسخة التكرارية بحلقة while. سنبحث عن 16 في المصفوفة [2, 5, 8, 12, 16, 23, 38].
Java — البحث الثنائي التكراري ▼
public class BinarySearch { public static int binarySearchIter(int[] arr, int target) { int low = 0, high = arr.length - 1; while (low <= high) { int mid = (low + high) / 2; if (arr[mid] == target) return mid; // Found! else if (arr[mid] < target) low = mid + 1; // Search right else high = mid - 1; // Search left } return -1; // Not found } public static void main(String[] args) { int[] arr = {2, 5, 8, 12, 16, 23, 38}; int idx = binarySearchIter(arr, 16); System.out.println("Found at index: " + idx); // Output: 4 } }

7.2 البحث الثنائي العودي (Recursive)

والآن النسخة العودية. نمرّر الفهرسين low وhigh كمعاملات ونضيّق نطاق البحث عوديًا. لاحظ: الحالة العودية هي عندما نجري أحد الاستدعاءين العوديين، والحالات الأساسية هي عندما نجد الهدف (نُرجع mid) أو عندما يكون النطاق فارغًا (نُرجع -1).
إذن كل استدعاء عودي يعمل على مصفوفة جزئية أصغر؟
بالضبط — نصف الحجم في كل مرة! ولهذا فإن البحث الثنائي من رتبة O(log n). بعد كل استدعاء، إما أن نكون قد وجدنا الجواب أو استبعدنا نصف العناصر.
Java — البحث الثنائي العودي ▼
public class BinarySearch { public static int binarySearchRec(int[] arr, int low, int high, int target) { if (low > high) return -1; // Base case: not found int mid = (low + high) / 2; if (arr[mid] == target) return mid; // Base case: found! else if (arr[mid] < target) return binarySearchRec(arr, mid + 1, high, target); // Search right else return binarySearchRec(arr, low, mid - 1, target); // Search left } public static void main(String[] args) { int[] arr = {2, 5, 8, 12, 16, 23, 38}; int idx = binarySearchRec(arr, 0, arr.length - 1, 16); System.out.println("Found at index: " + idx); // Output: 4 } }

8. الملخص

عمل ممتاز اليوم! لقد أتقنتم خمس دوال أساسية للعودية على السلاسل النصية والبحث الثنائي — بنسختيه التكرارية والعودية. لنتأمّل الأنماط الرئيسية.
الدالة الحالة الأساسية نوع الإرجاع مرحلة الطباعة / الحساب
printChars السلسلة الفارغة void الدفع PUSH (أثناء النزول)
printReverse السلسلة الفارغة void الإزالة POP (أثناء الصعود)
countChar فارغة → 0 int POP (تراكم)
replaceChar فارغة → "" String POP (بناء السلسلة)
removeChar فارغة → "" String POP (بناء السلسلة)
binarySearch وُجد / نطاق فارغ int POP (إرجاع الفهرس)
أهم الخلاصات:
  1. الدوال التي لا تُرجع قيمة (void) (printChars، printReverse) لا تختلف إلا في موضع تنفيذ الإجراء نسبةً إلى الاستدعاء العودي.
  2. الدوال التي تُرجع قيمة (countChar، replaceChar، removeChar) تبني نتيجتها أثناء مرحلة الرجوع.
  3. s.charAt(0) + s.substring(1) هو المقابل النصي لـ n + n-1 في العودية العددية.
  4. البحث الثنائي يطبّق العودية على البحث — كل استدعاء ينصّف حجم المسألة، فيمنحنا كفاءة O(log n).
  5. مكدس الاستدعاءات هو نموذجك الذهني — راقب الإطارات وهي تُدفع وتُزال، وافهم متى يحدث الحساب.
في الدرس القادم سنستكشف خوارزميات الترتيب — بأسلوبيها التكراري والعودي مثل الترتيب بالدمج (Merge Sort) والترتيب السريع (Quick Sort). التفكير العودي الذي بنيتموه هنا سيجعل تلك الموضوعات أسهل بكثير!
