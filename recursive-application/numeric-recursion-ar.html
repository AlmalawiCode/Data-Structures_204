العودية العددية (Numeric Recursion)

هياكل البيانات 1

حل المسائل الرياضية بالعودية

1. مقدمة

مرحبًا بكم مجددًا يا طلابي! في الدروس السابقة تعلمنا ما هي العودية (Recursion) وكيف تعمل في الذاكرة، ورأينا أيضًا كيف تستكشف العودية بنية المجلدات بأناقة. حان الوقت الآن لنرى العودية مطبَّقة على المسائل الرياضية.
مثل المضروب (Factorial) وفيبوناتشي (Fibonacci) يا أستاذ؟
بالضبط! سنعمل اليوم على سبع مسائل عودية عددية. في كل مسألة سأعرض لكم كود Java، ثم نتتبع مكدس الاستدعاءات (Call Stack) خطوة بخطوة — نشاهد الإطارات (Frames) وهي تُدفع إلى المكدس وتُخرج منه، ونرى القيم المعادة (Return Values) وهي تتراكم أثناء انحلال المكدس.
ما سنغطيه اليوم:
  1. المضروب (Factorial) — n!
  2. مجموع أول n عدد صحيح — 1 + 2 + ... + n
  3. القوة (Power) — baseexp
  4. الأس السريع (Fast Exponentiation) — قوة بتعقيد O(log n)
  5. الضرب العودي (Recursive Multiplication) — حساب a × b بالجمع
  6. فيبوناتشي (Fibonacci) — عودية متفرعة
  7. مجموع الأرقام (Sum of Digits) — استخراج الأرقام
تذكروا الجزأين اللذين لا تخلو منهما أي دالة عودية:
  • الحالة الأساسية (Base Case) — الشرط الذي يوقف العودية
  • الحالة العودية (Recursive Case) — الدالة تستدعي نفسها بمسألة أصغر

2. المضروب Factorial(5)

لنبدأ بالمثال الكلاسيكي: المضروب (Factorial). مضروب العدد n (ويُكتب n!) هو حاصل ضرب جميع الأعداد الصحيحة الموجبة من 1 إلى n. مثلًا: 5! = 5 × 4 × 3 × 2 × 1 = 120.
التعريف العودي:
fact(0) = 1      (الحالة الأساسية)
fact(n) = n × fact(n − 1)      (الحالة العودية، عندما n > 0)
Java - المضروب العودي ▼
public class Factorial { public static int factorial(int n) { if (n == 0) return 1; // Base case return n * factorial(n - 1); // Recursive case } public static void main(String[] args) { int result = factorial(5); System.out.println("5! = " + result); // Output: 5! = 120 } }

محاكاة تفاعلية: factorial(5)

3. مجموع أول n عدد صحيح — sum(5)

لنحسب الآن المجموع 1 + 2 + 3 + 4 + 5 بالعودية. هذا شبيه جدًا بالمضروب، لكن باستخدام الجمع بدل الضرب.
التعريف العودي:
sum(0) = 0      (الحالة الأساسية)
sum(n) = n + sum(n − 1)      (الحالة العودية، عندما n > 0)
Java - المجموع العودي ▼
public class SumOfN { public static int sum(int n) { if (n == 0) return 0; // Base case return n + sum(n - 1); // Recursive case } public static void main(String[] args) { int result = sum(5); System.out.println("Sum = " + result); // Output: Sum = 15 } }

محاكاة تفاعلية: sum(5)

القيم المعادة
راقبوا القيم المعادة بعناية! كل إطار يضيف قيمة n الخاصة به إلى النتيجة القادمة من الأسفل. تتراكم القيم: 0 → 1 → 3 → 6 → 10 → 15.

4. القوة Power(2, 4)

لنحسب الآن 24 = 16 بالعودية. الفكرة بسيطة: baseexp = base × baseexp−1، وbase0 = 1.
التعريف العودي:
pow(base, 0) = 1      (الحالة الأساسية)
pow(base, exp) = base × pow(base, exp − 1)      (الحالة العودية)
Java - القوة العودية ▼
public class Power { public static int power(int base, int exp) { if (exp == 0) return 1; // Base case return base * power(base, exp - 1); // Recursive case } public static void main(String[] args) { int result = power(2, 4); System.out.println("2^4 = " + result); // Output: 2^4 = 16 } }

محاكاة تفاعلية: power(2, 4)

5. الأس السريع Fast Exponentiation(2, 10)

بدل الضرب مرة تلو الأخرى، يمكننا تنصيف الأس عندما يكون زوجيًا! إذا أردنا 210، نحسب 25 مرة واحدة ثم نربّعه: (25)2. هذا يقلّل عدد الاستدعاءات العودية من O(n) إلى O(log n)!
خوارزمية القوة السريعة:
fastPow(base, 0) = 1      (الحالة الأساسية)
إذا كان exp زوجيًا: half = fastPow(base, exp/2)، ثم نعيد half × half
إذا كان exp فرديًا: نعيد base × fastPow(base, exp − 1)
Java - الأس السريع ▼
public class FastPower { public static int fastPow(int base, int exp) { if (exp == 0) return 1; // Base case if (exp % 2 == 0) { // Even exponent int half = fastPow(base, exp / 2); return half * half; // Square the half } else { // Odd exponent return base * fastPow(base, exp - 1); // Reduce to even } } public static void main(String[] args) { int result = fastPow(2, 10); System.out.println("2^10 = " + result); // Output: 2^10 = 1024 } }

6. الضرب العودي Multiplication(4, 3)

ماذا لو قلت لكم: احسبوا 4 × 3 دون استخدام عامل الضرب؟ لا يمكنكم استخدام سوى الجمع! الفكرة: 4 × 3 = 4 + 4 + 4، أي جمع العدد 4 مع نفسه 3 مرات.
التعريف العودي:
mult(a, 0) = 0      (الحالة الأساسية: أي عدد مضروب في صفر يساوي صفرًا)
mult(a, b) = a + mult(a, b − 1)      (الحالة العودية)
Java - الضرب العودي ▼
public class RecursiveMultiply { public static int multiply(int a, int b) { if (b == 0) return 0; // Base case return a + multiply(a, b - 1); // Recursive case } public static void main(String[] args) { int result = multiply(4, 3); System.out.println("4 x 3 = " + result); // Output: 4 x 3 = 12 } }

محاكاة تفاعلية: multiply(4, 3)

القيم المعادة
النمط: لاحظوا كيف يضيف كل إخراج من المكدس 4 إلى النتيجة السابقة: 0 → 4 → 8 → 12. نحن نبني حاصل الضرب بالجمع المتكرر!

7. فيبوناتشي Fibonacci(5)

نصل الآن إلى مسألة مميزة جدًا: أعداد فيبوناتشي (Fibonacci). متتالية فيبوناتشي هي قائمة من الأعداد كل عدد فيها هو مجموع العددين السابقين له. وعلى خلاف جميع أمثلتنا السابقة، تقوم دالة فيبوناتشي باستدعاءين عوديين اثنين! وهذا يُنشئ شجرة متفرعة من الاستدعاءات.
متتالية فيبوناتشي: 1, 1, 2, 3, 5, 8, 13, 21, ...
كل عدد هو مجموع العددين السابقين له.

Fib(1) = 1,   Fib(2) = 1      (حالتان أساسيتان!)
Fib(n) = Fib(n − 1) + Fib(n − 2)      (عندما n ≥ 3)
Java - فيبوناتشي العودي ▼
public class Fibonacci { public static int fib(int n) { if (n <= 2) return 1; // Base cases: fib(1)=1, fib(2)=1 return fib(n - 1) + fib(n - 2); // Two recursive calls! } public static void main(String[] args) { int result = fib(5); System.out.println("fib(5) = " + result); // Output: fib(5) = 5 } }
لنفهم أولًا كيف تعمل فيبوناتشي برسم شجرة الاستدعاءات (Call Tree). لإيجاد Fib(5) نحتاج إلى Fib(4) وFib(3). ولإيجاد Fib(4) نحتاج إلى Fib(3) وFib(2). نستمر في التفكيك حتى نصل إلى الحالات الأساسية!

اضغط «ابدأ» لترى كيف نفكك Fib(5) ونحسب الجواب خطوة بخطوة.
رائع! الآن ترون كيف تتدفق القيم صعودًا من الحالات الأساسية لتعطينا Fib(5) = 5. لكن كيف ينفّذ الحاسوب هذا فعليًا؟ إنه يستخدم مكدس الاستدعاءات (Call Stack)! لنشاهد المكدس أثناء العمل.
لاحظوا: تُحسب Fib(3) مرتين، وتُحسب Fib(2) ثلاث مرات. لحساب Fib(5) وحدها نقوم بـ9 استدعاءات! وهذا التكرار ينمو أسّيًا — فحساب Fib(40) يتطلب أكثر من 300 مليون استدعاء!

محاكاة تفاعلية: Fib(5) — اجتياز بالعمق أولًا (DFS)

شاهد المكدس وهو ينمو ويتقلص بينما نجتاز شجرة الاستدعاءات بالعمق أولًا.

القيم المعادة
يا طلابي، أريدكم أن تلاحظوا أمرًا مهمًا جدًا في هذه المحاكاة. نعم، قامت Fib(5) بـ9 استدعاءات في المجموع، وستقوم Fib(10) بـ109 استدعاءات، وFib(40) بأكثر من 300 مليون استدعاء. هذه أعداد ضخمة! لكن انظروا بعناية إلى المكدس — هل كانت الاستدعاءات التسعة كلها في المكدس في الوقت نفسه؟ لا!
ملاحظة أساسية: المكدس لا يحتفظ بجميع الاستدعاءات في آن واحد!

شاهدوا المحاكاة مرة أخرى بعناية. يتعمق المكدس في الفرع الأيسر أولًا، وعندما ينتهي استدعاء ما يُخرج إطاره من المكدس قبل أن يبدأ الفرع الأيمن أصلًا. أقصى عدد من الإطارات في المكدس في أي لحظة لحساب Fib(5) هو 5 فقط (main + عمق الشجرة)، وليس 9 (مجموع الاستدعاءات).

هذا تمامًا مثل مستكشف المجلدات في درسنا السابق — إذا كان لديكم آلاف الملفات في شجرة مجلدات، فإن الحاسوب لا يحمّلها كلها في الذاكرة دفعة واحدة، بل يتعمق في مجلد واحد، وينهيه، ثم يعود، ثم يدخل المجلد التالي.

لو كانت جميع الاستدعاءات مكدسة في الوقت نفسه لكانت العودية غير عملية — إذ ستفيض الذاكرة فورًا تقريبًا! بدلًا من ذلك، لا يحتفظ المكدس إلا بـالمسار الحالي من main() نزولًا إلى الاستدعاء النشط. في Fib(n)، أقصى عمق للمكدس هو O(n) فقط، مع أن مجموع عدد الاستدعاءات هو O(2n).

التعقيد: فيبوناتشي العودية الساذجة تعقيدها O(2n) — أسّي! والسبب كل تلك الحسابات المكررة. في مقررات لاحقة ستتعلمون تقنيات مثل التخزين المؤقت للنتائج (Memoization) والبرمجة الديناميكية (Dynamic Programming) لمعالجة ذلك.

8. مجموع الأرقام Sum of Digits(6573)

في مسألتنا الأخيرة، لنحسب مجموع أرقام عدد ما. مثلًا: أرقام العدد 6573 هي 6 و5 و7 و3، ومجموعها 6 + 5 + 7 + 3 = 21.
كيف نستخرج الأرقام واحدًا واحدًا بالعودية؟
بعمليتين: n % 10 تعطي الرقم الأخير، وn / 10 تعطي الأرقام المتبقية. نستمر في الاستخراج حتى يبقى رقم واحد (n < 10).
التعريف العودي:
sumDigits(n) = n      إذا كان n < 10 (رقم واحد — الحالة الأساسية)
sumDigits(n) = (n % 10) + sumDigits(n / 10)      (الحالة العودية)
Java - مجموع الأرقام ▼
public class SumOfDigits { public static int sumDigits(int n) { if (n < 10) return n; // Base case: single digit return (n % 10) + sumDigits(n / 10); // Last digit + rest } public static void main(String[] args) { int result = sumDigits(6573); System.out.println("Sum = " + result); // Output: Sum = 21 } }

محاكاة تفاعلية: sumDigits(6573)

9. الخلاصة

عمل ممتاز اليوم يا طلابي! لنراجع المسائل السبع جنبًا إلى جنب.
المسألة الحالة الأساسية الصيغة العودية التعقيد
المضروب fact(0) = 1 n × fact(n−1) O(n)
المجموع sum(0) = 0 n + sum(n−1) O(n)
القوة pow(b,0) = 1 b × pow(b, n−1) O(n)
القوة السريعة fPow(b,0) = 1 half² أو b × fPow O(log n)
الضرب mult(a,0) = 0 a + mult(a, b−1) O(b)
فيبوناتشي Fib(1)=1, Fib(2)=1 fib(n−1) + fib(n−2) O(2n)
مجموع الأرقام n < 10 → n (n%10) + sumDig(n/10) O(digits)

الخلاصات الرئيسية

  1. كل مسألة عودية لها حالة أساسية وحالة عودية.
  2. العودية الخطية (Linear Recursion) (المضروب، المجموع، القوة، الضرب، الأرقام) تقوم باستدعاء واحد في كل خطوة — فينمو المكدس خطيًا.
  3. العودية المتفرعة (Branching Recursion) (فيبوناتشي) تقوم باستدعاءات متعددة — وقد يؤدي ذلك إلى زمن أسّي.
  4. الأس السريع يبين كيف يمكن لبنية عودية ذكية أن تقلّل O(n) إلى O(log n).
  5. القيم المعادة تتدفق إلى الأعلى أثناء مرحلة الانحلال — وهنا يحدث الحساب الفعلي!
في الدرس القادم سنستكشف العودية على السلاسل النصية (String Recursion) — عكس السلاسل، وعدّ الأحرف، وغير ذلك. الأنماط نفسها التي تعلمتموها اليوم ستنطبق هناك أيضًا. واصلوا التدريب!
