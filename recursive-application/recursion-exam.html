public static boolean isPal(String s) {    if (s.length() <= 1) {                         // (i)        return true;    }    if (s.charAt(0) != s.charAt(s.length() - 1)) {  // (ii)        return false;    }    return isPal(s.substring(1, s.length() - 1));  // (iii) drop first and last}

Write your complete method:
Model Answer — Q6
public static int exam06(int n, int d) {    if (n == 0) {                        // base case: no digits left        return 0;    }    if (n % 10 == d) {                   // last digit matches        return 1 + exam06(n / 10, d);    }    return exam06(n / 10, d);            // last digit does not match}

Q7 String Recursion — Remove Adjacent Duplicates HARD CLO 8SO-2 10 marks

Write  public static String exam07(String s)  that returns a new string in which every run of adjacent equal characters is reduced to a single character. Characters that are equal but not adjacent are kept.

Note: you will not get points unless you use recursion (no loops).

Worked examples.  "aabbbcda" → "abcda"  ·  "xxxx" → "x"  ·  "abc" → "abc"  ·  "" → ""

Hint: compare s.charAt(0) with s.charAt(1); then recurse on s.substring(1).

Write your complete method:
Model Answer — Q7
public static String exam07(String s) {    if (s.length() <= 1) {                   // base case: "" or one char        return s;    }    if (s.charAt(0) == s.charAt(1)) {        // duplicate: drop the first one        return exam07(s.substring(1));    }    return s.charAt(0) + exam07(s.substring(1));   // keep it, solve the rest}

Rubric (10): base case for length 0 and 1 3 (a base case of only "" causes charAt(1) to crash on one character) · compare first two chars 2 · drop duplicate correctly 2 · keep + concatenate with recursive result 3. A loop-based answer earns 0.

Note: you will not get points unless you use recursion (no loops).

(a) Write your complete method: [7 marks]

(b) For the array below, list the values of mid in the order they are computed for key = 56 and for key = 10, and give the returned value. [3 marks]

3812172130425663
012345678
key = 56: mids = ______________   returns ______
key = 10: mids = ______________   returns ______
Model Answer — Q10
public static int exam10(int[] a, int key, int lo, int hi) {    if (lo > hi) {                        // base case: empty range, not found        return -1;    }    int mid = (lo + hi) / 2;    if (a[mid] == key) {                  // base case: found        return mid;    }    if (key < a[mid]) {        return exam10(a, key, lo, mid - 1);   // search left half    }    return exam10(a, key, mid + 1, hi);       // search right half}

(b) key = 56: mids 4, 6, 7 → returns 7.   key = 10: mids 4, 1, 2 → returns −1.

(a) both base cases 3 · correct mid 1 · correct left/right recursive calls with mid ± 1 3 (using mid instead of mid ± 1 can recurse forever) · (b) 1.5 each. A loop-based answer earns 0 for (a).
