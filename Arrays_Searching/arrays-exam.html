Write  public static int exam05(int[] a, int size, int pos, int value)  that inserts value at index pos, shifting the elements at pos … size-1 one place to the right, and returns the new size. Assume 0 ≤ pos ≤ size and size < a.length.

Worked example.  exam05(a, 4, 1, 19) → a becomes 12, 19, 25, 31, 48 and the method returns 5.

Hint: shift starting from the right end, otherwise you overwrite values before moving them.

Write your complete method:
Model Answer — Q5
public static int exam05(int[] a, int size, int pos, int value) {    for (int i = size; i > pos; i--) {   // right-to-left shift        a[i] = a[i - 1];    }    a[pos] = value;    return size + 1;}

Rubric: loop starts at size and goes down 2 · correct stop condition i > pos 2 · a[i] = a[i-1] 2 · place value 1 · return size + 1  1. A left-to-right shift copies one value into every cell (−4).

Model Answer — Q7
public static int[] exam07(int[] a) {    int count = 0;                       // pass 1: count evens    for (int i = 0; i < a.length; i++) {        if (a[i] % 2 == 0) count++;    }    int[] result = new int[count];    int k = 0;                           // pass 2: fill    for (int i = 0; i < a.length; i++) {        if (a[i] % 2 == 0) {            result[k] = a[i];            k++;        }    }    return result;}

Q9 Recursive Binary Search HARD SO-2 10 marks

Write  public static int exam09(int[] a, int low, int high, int target)  that searches the sorted range a[low … high] using binary search and returns the index of target, or -1 if it is not there. The first call is exam09(a, 0, a.length - 1, target).

Note: you will not get points unless you use recursion (no loops).

Worked example.  a = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91}: target 23 → 5; target 91 → 9; target 10 → -1.
Write your complete method:
Model Answer — Q9
public static int exam09(int[] a, int low, int high, int target) {    if (low > high) {                   // base case: empty range        return -1;    }    int mid = (low + high) / 2;    if (a[mid] == target) {             // base case: found        return mid;    }    if (target < a[mid]) {        return exam09(a, low, mid - 1, target);    // left half    }    return exam09(a, mid + 1, high, target);       // right half}

Rubric: base case low > high → -1  2 · compute mid 1 · found → return mid 2 · left recursive call with mid - 1 2 · right recursive call with mid + 1 2 · returning the recursive result 1. Passing mid instead of mid ± 1 can recurse forever (−2). A loop-based answer earns 0.

Write  public static int[] exam10(int[] a, int[] b)  where both a and b are sorted in ascending order. Return a new array of length a.length + b.length that contains all values of both arrays, also sorted in ascending order. Your method must run in O(n + m): do not copy everything and then sort.

a
149
b
231012
result
123491012

Hint: keep one index for a, one for b, and one for the result. When one array runs out, copy the rest of the other. Your code must also work when one of the arrays is empty.

Write your complete method:
Model Answer — Q10
public static int[] exam10(int[] a, int[] b) {    int[] r = new int[a.length + b.length];    int i = 0, j = 0, k = 0;    while (i < a.length && j < b.length) {   // take the smaller front value        if (a[i] <= b[j]) {            r[k++] = a[i++];        } else {            r[k++] = b[j++];        }    }    while (i < a.length) r[k++] = a[i++];      // leftovers of a    while (j < b.length) r[k++] = b[j++];      // leftovers of b    return r;}

Rubric: allocate correct length 1 · three indices 1 · main loop with && condition 2 · compare and copy the smaller, advancing the right indices 3 · copy leftovers of both arrays 2 · return 1. Copying then sorting: max 4/10.
