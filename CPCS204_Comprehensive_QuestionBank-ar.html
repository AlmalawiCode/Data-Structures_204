عن هذا الكتيّب

هذه الوثيقة كتيّب مراجعة شامل لمقرر هياكل البيانات 1. وهو منظَّم على هيئة بنك أسئلة موزَّع على اثني عشر جزءًا، تتدرّج من المفاهيم الأساسية إلى مسائل التتبّع المتقدمة، وينتهي بـمفتاح الإجابات وورقة التلميحات. والغاية منه أن يعرّفك على كل نمط متكرر من الأسئلة قد يظهر في الاختبارات الفصلية والنهائية.

يحمل كل سؤال وسمًا يبيّن مستوى صعوبته: سهل متوسط صعب. وترافق الرسومُ التوضيحية كثيرًا من الأسئلة لتوضيح هيكل البيانات أو الخوارزمية المعنية. وقد هُيّئ الكتيّب للقراءة على الشاشة وللطباعة على ورق A4 معًا.

ملاحظة (للعرض على الشاشة فقط): تُرسَم مخططات الأشجار والكومات والقوائم والمخططات البيانية باستخدام مكتبة Mermaid. إذا ظهر أحد الرسوم فارغًا، فتأكد من اتصال الصفحة بالإنترنت عند التحميل الأول، ثم أعد تحميلها.

السؤال 1.6 — تحليل العلاقات التكرارية صعب[8 درجات]

أعطِ حدًّا محكمًا بترميز Big-O لكل علاقة تكرارية (Recurrence). علّل باختصار بالتعويض أو برسم شجرة العودية (Recursion Tree) رسمًا تقريبيًا.

  1. T(n) = T(n−1) + n، T(1) = 1
  2. T(n) = 2·T(n/2) + n، T(1) = 1
  3. T(n) = T(n/2) + 1، T(1) = 1
  4. T(n) = 2·T(n−1) + 1، T(0) = 1

السؤال 2.3 — تتبّع أسلوب فرّق تسُد (Divide-and-Conquer) متوسط[10 درجات]

public static int find(int[] a, int lo, int hi) {
    if (lo == hi) return a[lo];
    int mid   = (lo + hi) / 2;
    int left  = find(a, lo, mid);
    int right = find(a, mid + 1, hi);
    return Math.max(left, right);
}
