شبكة الصيدليات - اجتياز DFS

القاعدة

زُر الصيدلية المتصلة بالطريق ذي أعلى مستوى ازدحام أولًا.

السؤال: اجتياز DFS

يبدأ علي من الصيدلية A. باستخدام البحث بالعمق أولًا (DFS)، اكتب الترتيب الذي يزور به جميع الصيدليات:

A → ___ → ___ → ___ → ___ → ___ → ___ → ___ → ___ → ___

الحل

اجتياز DFS خطوة بخطوة

الخطوة 1: ابدأ من A
المُزارة: {A} | المكدس: []
جيران A: B(18), C(15), D(10)
ادفع (Push) C، D إلى المكدس (Stack). اختر B (الأعلى = 18)
المكدس بعد ذلك: [D, C]
الخطوة 2: انتقل إلى B
المُزارة: {A, B} | المكدس: [D, C]
جيران B: A(18)✓, E(12)
اختر E (الأعلى غير المُزار = 12)
المكدس بعد ذلك: [D, C]
الخطوة 3: انتقل إلى E
المُزارة: {A, B, E} | المكدس: [D, C]
جيران E: F(14), B(12)✓
اختر F (الأعلى غير المُزار = 14)
المكدس بعد ذلك: [D, C]
الخطوة 4: انتقل إلى F
المُزارة: {A, B, E, F} | المكدس: [D, C]
جيران F: E(14)✓
طريق مسدود! جميع الجيران مُزارة. اسحب (Pop) من المكدس ← C
المكدس بعد ذلك: [D]
الخطوة 5: ارجع (Backtrack) إلى C (من المكدس)
المُزارة: {A, B, E, F, C} | المكدس: [D]
جيران C: G(16), A(15)✓, D(5)
ادفع D إلى المكدس. اختر G (الأعلى غير المُزار = 16)
المكدس بعد ذلك: [D, D]
الخطوة 6: انتقل إلى G
المُزارة: {A, B, E, F, C, G} | المكدس: [D, D]
جيران G: C(16)✓, H(8)
اختر H (الأعلى غير المُزار = 8)
المكدس بعد ذلك: [D, D]
الخطوة 7: انتقل إلى H
المُزارة: {A, B, E, F, C, G, H} | المكدس: [D, D]
جيران H: I(19), D(17), J(11), G(8)✓
ادفع D، J إلى المكدس. اختر I (الأعلى غير المُزار = 19)
المكدس بعد ذلك: [D, D, D, J]
الخطوة 8: انتقل إلى I
المُزارة: {A, B, E, F, C, G, H, I} | المكدس: [D, D, D, J]
جيران I: H(19)✓, J(6)
اختر J (الأعلى غير المُزار = 6)
المكدس بعد ذلك: [D, D, D, J]
الخطوة 9: انتقل إلى J
المُزارة: {A, B, E, F, C, G, H, I, J} | المكدس: [D, D, D, J]
جيران J: H(11)✓, I(6)✓
طريق مسدود! اسحب من المكدس ← J (مُزارة)، D (مُزارة)، D (مُزارة)، D
المكدس بعد ذلك: []
الخطوة 10: ارجع إلى D (من المكدس)
