تتبّع الدوال العودية (Recursive Methods) خطوة بخطوة

التعليمات

  • في كل سؤال، تتبّع استدعاء الدالة المعطى يدويًا.
  • ارسم جميع الاستدعاءات العودية على شكل صناديق، مع إظهار المعاملات (Parameters) والمتغيرات المحلية (Local Variables) في كل مستوى.
  • بيّن القيمة النهائية التي يُعيدها الاستدعاء الأصلي.
  • انقر على «عرض الحل» للتحقق من إجابتك بعد أن تُكمل التتبّع.

مجموع مربعات الأرقام
تستقبل الدالة العودية (Recursive Method) التالية عددًا صحيحًا n وتُعيد مجموع مربعات أرقامه. تستخرج الدالة الرقم الأخير باستخدام n % 10، ثم تُربّعه وتُضيفه إلى ناتج معالجة الأرقام المتبقية n / 10. تتوقف العودية (Recursion) عندما تصل n إلى 0. تتبّع الدالة باستدعائها بـ sumSq(314). يجب أن ترسم جميع الاستدعاءات العودية وأن تبيّن الإجابة النهائية المُعادة.
Java - مجموع مربعات الأرقام ▼
public static int sumSq(int n) { if (n == 0) return 0; int d = n % 10; return (d * d) + sumSq(n / 10); }
تتبّع: sumSq(314)
تتبّع الحل
sumSq(314): d=4، return 16 + sumSq(31)
sumSq(31): d=1، return 1 + sumSq(3)
sumSq(3): d=3، return 9 + sumSq(0)
sumSq(0): الحالة الأساسية -- return 0
↑
sumSq(3) = 9 + 0 = 9
↑
sumSq(31) = 1 + 9 = 10
↑
sumSq(314) = 16 + 10 = 26
الإجابة النهائية: 26

حاصل ضرب الأرقام
تستقبل الدالة العودية التالية عددًا صحيحًا n وتُعيد حاصل ضرب جميع أرقامه. تستخرج الدالة الرقم الأخير باستخدام n % 10 وتضربه في حاصل ضرب الأرقام المتبقية n / 10. الحالة الأساسية (Base Case) هي عندما تكون n رقمًا واحدًا (أقل من 10)، وفي هذه الحالة تُعيد n نفسها. تتبّع الدالة باستدعائها بـ prodDigits(2431). يجب أن ترسم جميع الاستدعاءات العودية وأن تبيّن الإجابة النهائية المُعادة.
Java - حاصل ضرب الأرقام ▼
public static int prodDigits(int n) { if (n < 10) return n; return (n % 10) * prodDigits(n / 10); }
تتبّع: prodDigits(2431)
تتبّع الحل
prodDigits(2431): return 1 * prodDigits(243)
prodDigits(243): return 3 * prodDigits(24)
prodDigits(24): return 4 * prodDigits(2)
prodDigits(2): الحالة الأساسية (2 < 10) -- return 2
↑
prodDigits(24) = 4 * 2 = 8
↑
prodDigits(243) = 3 * 8 = 24
↑
prodDigits(2431) = 1 * 24 = 24
الإجابة النهائية: 24

الإبقاء على الأرقام الزوجية فقط
تستقبل الدالة العودية التالية عددًا صحيحًا n وتُعيد عددًا جديدًا يحتوي على الأرقام الزوجية فقط من العدد الأصلي، مع الحفاظ على ترتيبها. تفحص الدالة كل رقم: إذا كان الرقم زوجيًا فإنه يُحتفظ به في الناتج بضرب الناتج العودي في 10 ثم إضافة الرقم. وإذا كان الرقم فرديًا فإنه يُتخطّى. تتوقف العودية عندما تصل n إلى 0. تتبّع الدالة باستدعائها بـ keepEven(56283). يجب أن ترسم جميع الاستدعاءات العودية وأن تبيّن الإجابة النهائية المُعادة.
Java - الإبقاء على الأرقام الزوجية فقط ▼
public static int keepEven(int n) { if (n == 0) return 0; int d = n % 10; if (d % 2 == 0) return keepEven(n / 10) * 10 + d; else return keepEven(n / 10); }
تتبّع: keepEven(56283)
تتبّع الحل
keepEven(56283): d=3، فردي -- return keepEven(5628)
keepEven(5628): d=8، زوجي -- return keepEven(562) * 10 + 8
keepEven(562): d=2، زوجي -- return keepEven(56) * 10 + 2
keepEven(56): d=6، زوجي -- return keepEven(5) * 10 + 6
keepEven(5): d=5، فردي -- return keepEven(0)
keepEven(0): الحالة الأساسية -- return 0
↑
keepEven(5) = 0
↑
keepEven(56) = 0 * 10 + 6 = 6
↑
keepEven(562) = 6 * 10 + 2 = 62
↑
keepEven(5628) = 62 * 10 + 8 = 628
↑
keepEven(56283) = 628
الإجابة النهائية: 628

اللغز ذو المعاملين
تستقبل الدالة العودية التالية عددين صحيحين a وb. عندما تصل b إلى 0 تُعيد a (الحالة الأساسية). وفيما عدا ذلك، تتحقق مما إذا كانت a زوجية أم فردية: إذا كانت a زوجية فإنها تقسم a على 2، وتُنقص b بمقدار 1، وتُضيف b إلى الناتج. وإذا كانت a فردية فإنها تزيد a بمقدار 1 وتُنقص b بمقدار 1 دون إضافة أي شيء. تتبّع الدالة باستدعائها بـ mystery(7, 3). يجب أن ترسم جميع الاستدعاءات العودية وأن تبيّن الإجابة النهائية المُعادة.
Java - اللغز ذو المعاملين ▼
public static int mystery(int a, int b) { if (b == 0) return a; if (a % 2 == 0) return mystery(a / 2, b - 1) + b; else return mystery(a + 1, b - 1); }
تتبّع: mystery(7, 3)
تتبّع الحل
mystery(7, 3): 7 فردي -- return mystery(8, 2)
mystery(8, 2): 8 زوجي -- return mystery(4, 1) + 2
mystery(4, 1): 4 زوجي -- return mystery(2, 0) + 1
mystery(2, 0): b=0، الحالة الأساسية -- return 2
↑
mystery(4, 1) = 2 + 1 = 3
↑
mystery(8, 2) = 3 + 2 = 5
↑
mystery(7, 3) = 5
الإجابة النهائية: 5

العودية المتفرعة
تستقبل الدالة العودية التالية عددًا صحيحًا n. إذا كانت n ≤ 1 فإنها تُعيد n (الحالة الأساسية). وفيما عدا ذلك، تتحقق مما إذا كانت n زوجية أم فردية: إذا كانت n زوجية فإنها تُجري استدعاءين عوديين — branch(n/2) وbranch(n-1) — وتُعيد مجموعهما. وإذا كانت n فردية فإنها تُعيد n مضافًا إليها branch(n-2). ولأن الحالة الزوجية تُنشئ فرعين، فإن هذا يُنتج شجرة استدعاءات (Call Tree) وليس مجرد سلسلة. تتبّع الدالة باستدعائها بـ branch(6). يجب أن ترسم شجرة الاستدعاءات كاملة وأن تبيّن الإجابة النهائية المُعادة.
Java - العودية المتفرعة ▼
public static int branch(int n) { if (n <= 1) return n; if (n % 2 == 0) return branch(n / 2) + branch(n - 1); else return n + branch(n - 2); }
تتبّع: branch(6)

التفرّع ذو المعاملين
تستقبل الدالة العودية التالية عددين صحيحين a وb. إذا تحقق أيٌّ من a ≤ 0 أو b ≤ 0 فإنها تُعيد 1 (الحالة الأساسية). وفيما عدا ذلك، تتحقق مما إذا كان a ≥ b: فإن كان كذلك تُعيد a مضافًا إليها استدعاءً عوديًا واحدًا solve(a-2, b-1). وإذا كان a < b فإنها تُجري استدعاءين عوديين — solve(a, b-1) وsolve(a-1, b) — وتُعيد مجموعهما. تُنتج حالة الفرعين شجرة استدعاءات. تتبّع الدالة باستدعائها بـ solve(2, 3). يجب أن ترسم شجرة الاستدعاءات كاملة وأن تبيّن الإجابة النهائية المُعادة.
Java - التفرّع ذو المعاملين ▼
public static int solve(int a, int b) { if (a <= 0 || b <= 0) return 1; if (a >= b) return a + solve(a - 2, b - 1); else return solve(a, b - 1) + solve(a - 1, b); }
